# Exercise 6.6
> Explain the differences between a parameter, a local variable, and a local static variable. Give an example of a function in which each might be useful.

## Solution

- **Local variables** are automatic objects created within a scope (`{ }`), and unless explicitly initialized, they have an undefined value. Upon exiting the block (`{ }`), they are destroyed and any reference to them leads to undefined behavior.
  ```c++
  //The variable i exists only within the loop scope; it cannot be accessed outside of it
  for (size_t i = 0; i < size; ++i) { /* ... */ }
  ```
  
- Function **parameters** are local variables defined inside a function's parameter list, and have to be initialized with a value.
  ```c++
  //The function gets an integer outside the function and calculates its square
  int foo(int x) {
      return x * x;
  }
  ```

- **Local static variables** are variables whose lifetime extends until the end of the program rather than the end of a block (`{ }`). Local static variables may be initialized, but non-initialized variables are value-initialized. 
  ```c++
  //The variable jmpCnt counts the number of function calls and persists until the program ends
  void jump() {
      static int jmpCnt;
      ++jmpCnt;
      /* ... */
  }
  ```

# Exercise 6.7
> Write a function that returns 0 when it is first called and then generates numbers in sequence each time it is called again.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cout;
  int foo() {
      static int cnt = 0; //cnt is defined once during the entire program execution
      return cnt++; 
  }
  int main() {
      for (int i = 0; i < 5; ++i) {
          cout << foo();
      }
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Output:
    01234
    ```

# Exercise 6.19
> Given the following declarations, determine which calls are legal and which are illegal. For those that are illegal, explain why.

```c++
double calc(double);
int count(const string &, char);
int sum(vector<int>::iterator, vector<int>::iterator, int);
vector<int> vec(10);
```

(a) `calc(23.4, 55.1); ` <br>
(b) `count("abcda", ’a’);` <br>
(c) `calc(66);` <br>
(d) `sum(vec.begin(), vec.end(), 3.8);`

## Solution

a) The call is invalid because the function takes only one argument. <br>
b) Valid. A `const` reference parameter allows us to pass a `string` literal as an argument. <br>
c) Valid. The `int` argument is implicitly converted to a `double`. <br>
d) Valid. The `double` argument implicitly converted to a `int`, so the fractional part is truncated.

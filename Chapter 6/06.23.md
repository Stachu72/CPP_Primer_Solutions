# Exercise 6.23
> Write your own versions of each of the print functions presented in this section. Call each of these functions to print i and j defined as follows: `int i = 0, j[2] = {0, 1};`

## Solution

- _Using a Marker to Specify the Extent of an Array:_ <br>
  `i` and `j` do not have any end marker (`'/0'`) that the function requires.

  
- _Using the Standard Library Conventions:_ <br>
  The standard library convention requires us to pass two pointers: one to the first element and one past the last element.
  ```c++
  void print(int *beg, int *end) { /* ... */ }
  
  print(std::begin(j), std::end(j));
  ```
  
- _Explicitly Passing a Size Parameter:_
  ```c++
  void print(int arr[], size_t size) { /* ... */ }
  
  print(j, 2);
  print(&i, 0); //an array parameter is adjusted to a pointer parameter
  ``` 
  An array parameter is adjusted to a pointer parameter, so an `int*` can be passed as the first argument.


- _Array Reference Parameters:_
  ```c++
  void print(int (&arr)[2]) { /* ... */ }
  
  print(i); //i is not an array of 2 elements | Error
  print(j); //j is an array of excactly 2 elements | Valid
  ```
  
- _Passing a Multidimensional Array:_
  ```c++
  void print(int arr[][2], int rowSize) { /* ... */ }
  ```
  Neither `i` nor `j` is a multidimensional array, so neither can be passed to this function.

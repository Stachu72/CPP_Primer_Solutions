# Exercise 6.9
> Write your own versions of the fact.cc and factMain.cc files. These files should include your Chapter6.h from the exercises in the previous section. Use these files to understand how your compiler supports separate compilation.

## Solution

- **Files:**
  - `fact.cpp`:
    ```c++
    #include <iostream>
    #include "Chapter6.h"
    using std::cout; using std::cin;
    void fact() {
        unsigned x;
        cout << "Enter a non-negative integer: ";
        if (cin >> x) {
            unsigned result = 1;
            while (x > 1) {
                result *= x--;
            }
            cout << "The factorial of the given number is: " << result;
        }
    }
    ```
  - `factMain.cpp`:
    ```c++
    #include "Chapter6.h"
    int main() {
        fact();
        return 0;
    }
    ```

- **Commands:**
  ```
  g++ -c fact.cpp factMain.cpp
  g++ fact.o factMain.o -o main
  ```
  
- **How it works?**
  - The compiler processes each source file (`.cpp`) independently, creating file that contains object code (`.o`).
  - During compilation the file `factMain.cpp` doesn't know about the implementation of `fact()`, it only knows the function declaration without its memory address (`return type`, `parameters`).
  - The linker combines each object file (`.o`) into a single executable file (`.exe`).
  - The address of `fact()` from `fact.o` is inserted into its call site in `factMain.o`.

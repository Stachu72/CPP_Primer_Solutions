# Exercise 6.3
> Write and test your own version of fact.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cout;
  //the factorial function calculated using recursion
  int fact(unsigned x) {
      if (x > 1)
          return x * fact(x - 1); //returns x * (x-1) * (x-2) * ... * 1
      else
          return 1;
  }
  int main() {
      cout << fact(5);
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Output:
    120
    ```

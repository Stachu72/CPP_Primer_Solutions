# Exercise 6.17
> Write a function to determine whether a string contains any capital letters. Write a function to change a string to all lowercase. Do the parameters you used in these functions have the same type? If so, why? If not, why not?

## Solution

- _Write a function to determine whether a string contains any capital letters.:_
    ```c++
    bool anyCapital(const string &str) {
        for (const auto c : str) {
            if (isupper(c)) return true; //returns true when it finds an uppercase
        }
        return false;
    }
    ```
- _Write a function to change a string to all lowercase.:_
    ```c++
    void strToLower(string &str) {
        for (auto &c : str)
            c = tolower(c);
    }
    ```

The first function uses a `const` reference because it does not modify the `string` argument. Passing the argument by reference avoids unnecessary copying of the string, while `const` prevents the function from modifying the original string and allows us to pass a `const string` as the argument. The second function modifies the original string, so it uses a non-const reference. This avoids copying a potentially large string and allows the function to modify the original argument.

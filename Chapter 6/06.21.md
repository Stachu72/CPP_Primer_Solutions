# Exercise 6.21
> Write a function that takes an int and a pointer to an int and returns the larger of the int value or the value to which the pointer points. What type should you use for the pointer?

## Solution

- **Function Code:**
  ```c++
  int selectLarger(int x, const int *py) {
      return x > *py ? x : *py;
  }
  ```
  The pointer points to `const` int because the function only reads the value pointed to by the pointer.

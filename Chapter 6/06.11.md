# Exercise 6.11
> Write and test your own version of reset that takes a reference.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cout; using std::cin;
  //The function resets the higher value of the two arguments; if the values are equal, both arguments are reset
  void reset(int &x, int &y) {
      if (x >= y) x = 0;
      if (y >= x) y = 0;
  }
  int main() {
      int x = 10, y = -20, z = 10;
      reset(x, z);
      cout << "First reset: X = " << x << " Z = " << z << '\n';
      reset(x, y);
      cout << "Second reset: X = " << x << " Y = " << y << '\n';
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Output:
    First reset: X = 0 Z = 0
    Second reset: X = 0 Y = -20
    ```

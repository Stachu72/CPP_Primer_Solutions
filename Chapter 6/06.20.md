# Exercise 6.20
> When should reference parameters be references to const? What happens if we make a parameter a plain reference when it could be a reference to const?

## Solution

The rules about being references const or non-const are simple:
- Why should a reference be `non-const`?
  - When we want to modify the original argument passed to the function.
  - When the function should return more than one value.
- Why should a reference be `const`?
  - When the argument should not be modified.
  - When we want to use a `string` literal as an argument.
- _What happens if we make a parameter a plain reference when it could be a reference to const?_
  - Using a plain reference instead of a `const` reference limits the types of arguments that can be passed to the function. A plain reference cannot bind to a `const` object or a temporary value.

# Exercise 6.10
> Using pointers, write a function to swap the values of two ints. Test the function by calling it and printing the swapped values.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cout;
  void swap(int *x, int *y) {
      const int tempX = *x;
      *x = *y;
      *y = tempX;
  }
  int main() {
      int x = 10, y = -20;
      swap(&x, &y);
      cout << "Swapped values: X = " << x << " Y = " << y;
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Output:
    Swapped values: X = -20 Y = 10
    ```

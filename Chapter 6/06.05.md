# Exercise 6.5
> Write a function to return the absolute value of its argument.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cout;
  int abs(int x) {
      return x >= 0 ? x : -x;
  }
  int main() {
      cout << abs(-5);
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Output:
    5
    ```

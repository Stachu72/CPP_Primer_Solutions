# Exercise 6.14
> Give an example of when a parameter should be a reference type. Give an example of when a parameter should not be a reference.

## Solution

- A parameter should be a reference type when the function needs to change the original argument, or to avoid making a copy of a large type:
    ```c++
    //The function changes the original passed argument
    void foo(int &x) {
        x *= x;
    }
    
    //A string variable may be large, so we use a reference to avoid making a copy of it
    void foo2(string &str) { /* ... */ }
    ```
- A parameter passed by value is used when the original argument should not be changed, especially for small built-in types (e.g., `bool`, `char`, `int`) where copying is cheap:
    ```c++
    //We can modify the parameter inside the function without affecting the original argument.
    void foo(int x) { /* ... */ }
    ```

# Exercise 6.1
> What is the difference between a parameter and an argument?

## Solution

- A **Parameter** is a definition of a variable placed in function parentheses. It is used to receive data from outside the function:
  ```c++
  void foo(parameter1, parameter2...) { /* ... */ }
  ```
  The parameters are optional and consist of: `type (optional name)`, separated by a comma:
    ```c++
    void foo(int x, int y) { /* ... */ }
    ```
  
- An **argument** is data that is sent to a function. It is placed inside the call operator (`()`):
  ```c++
  foo(argument1, argument2...);
  ```
  Arguments must be of the same type as corresponding parameters (or must be converted to their type):
  ```c++
  void foo(int x, int y) { /* ... */ }
  
  int data1 = 0;
  float data2 = 20;
  foo(data1, data2); //data2 is truncated and used as int
  ```
  
We must pass exactly the same number of arguments as the function has parameters:
```c++
void foo(int x) { /* ... */ }
foo(); //error: too few arguments in function call
```

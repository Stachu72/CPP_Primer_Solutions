# Exercise 6.2
> Indicate which of the following functions are in error and why. Suggest
how you might correct the problems.

```c++
//(a) 
int f() {
    string s;
    // ...
    return s;
}

//(b) 
f2(int i) { /* ... */ }

//(c) 
int calc(int v1, int v1) /* ... */ }

//(d) 
double square(double x) return x * x;
```

## Solution

- The function return type must match the type of the returned value:
  ```c++
  //(a) 
  string f() { //the function f() is now returning a string value
      string s;
      // ...
      return s;
  }
  ```
- A function has to have a return type. If the function returns no value, use the void type instead:
  ```c++
  //(b) 
  void f2(int i) { /* ... */ } //the function returns no value
  ```
- (1) A function has to have a function body. (2) If a function returns a value other than void, a return statement with an appropriate value is required. (3) Parameter names must be unique: 
  ```c++
  //(c) 
  int calc(int v1, int v2) { //v1 and v2, not v1 and v1; the function now has a valid function body
      /* ... */ 
      return v1 + v2; //the function returns an int value
  }
  ```
- A function definition requires a function body enclosed in curly braces:
  ```c++
  //(d) 
  double square(double x) {
      return x * x; //return statement is enclosed within the function body
  }
  ```

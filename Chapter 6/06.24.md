# Exercise 6.24
> Explain the behavior of the following function. If there are problems in the code, explain what they are and how you might fix them.

```c++
void print(const int ia[10])
{
    for (size_t i = 0; i != 10; ++i)
        cout << ia[i] << endl;
}
```

## Solution

The following function has one major problem: The parameter `const int ia[10]` is adjusted to `const int* ia`, which means the function actually receives a pointer rather than an array. In this case, the simplest fix is to use a `reference to an array`. This solution requires the argument to be an array of 10 elements.

```c++
void print(const int (&ia)[10])
{
    for (size_t i = 0; i != 10; ++i)
        cout << ia[i] << endl;
}
```

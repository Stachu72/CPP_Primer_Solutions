# Exercise 6.13
> Assuming T is the name of a type, explain the difference between a function declared as `void f(T)` and `void f(T&)`.

## Solution

- The function `void f(T)` passes its argument by value. The parameter is initialized as a local copy of the passed argument. Any changes made to the parameter inside the function do not affect the original argument.
- The function `void f(T&)` passes its argument by reference. The parameter acts as an alias for the passed argument. No copy is made, and any changes made to the parameter directly modify the original argument.

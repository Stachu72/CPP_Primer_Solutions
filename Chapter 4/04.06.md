# Exercise 4.6
> Write an expression to determine whether an int value is even or odd.

## Solution

* **Code:**
  ```c++
  #include <iostream>
  using std::cin; using std::cout; using std::cerr; 
  int main() {
     int a;
     if (cin >> a)
        if (a % 2) //true if there is a remainder; false otherwise
           cout << "The given number is odd.";
        else
           cout << "The given number is even.";
     else {
        cerr << "No input?!";
        return -1;
     }
     return 0;
  }
  ```
  - Input/Output:
    - ```c++
      //Input:
      12
      //Output:
      The given number is even.
      ```
    - ```c++
      //Input:
      5
      //Output:
      The given number is odd.
      ```
    - ```c++
      //Input: (no input)

      //Output:
      No input?!
      ```

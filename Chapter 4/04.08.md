# Exercise 4.8
> Explain when operands are evaluated in the logical AND, logical OR, and equality operators.

## Solution
  
| Operators         | Use                | When evaluated as true?                  | Is the right operand evaluated?   |
|-------------------|--------------------|------------------------------------------|-----------------------------------|
| Equality `==`     | expr1 `==` expr2   | When its operands are the same           | Always                            |
| Inequality `!=`   | expr1 `!=` expr2   | When its operands differ                 | Always                            |
| Logical AND `&&`  | expr1 `&&` expr2   | When both operands evaluate as true   | Only if the left operand is true  |  
| Logical OR `\|\|` | expr1 `\|\|` expr2 | When either of operands evaluates as true | Only if the left operand is false |

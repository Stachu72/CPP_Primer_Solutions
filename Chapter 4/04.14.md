# Exercise 4.14
> Explain what happens in each of the if tests:

```c++
if (42 = i) //...
if (i = 42) //...
```

## Solution

```c++
if (42 = i) //the assignment operator (=) requires a modifiable lvalue as the left operand | Error
if (i = 42) //the value 42 is assigned to the variable i, which is always not equal to 0. Therefore, the condition is always true
```

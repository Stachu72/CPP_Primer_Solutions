# Exercise 4.28
> Write a program to print the size of each of the built-in types.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    using std::cout;
    int main() {
        cout << "Boolean size: "          << sizeof(bool)
             << "\nCharacter size: "      << sizeof(char)
             << "\nWide character size: " << sizeof(wchar_t)
             << "\nShort size: "          << sizeof(short)
             << "\nInteger size: "        << sizeof(int)
             << "\nLong size: "           << sizeof(long)
             << "\nLong Long size: "      << sizeof(long long)
             << "\nFloat size: "          << sizeof(float)
             << "\nDouble size: "         << sizeof(double)
             << "\nLong Double size: "    << sizeof(long double);
        return 0;
    }
    ```
  - Input/Output:
    ```c++
    //Output:
    /* Note: Evaluated on 64-bit Windows (x64, LLP64 model, compiled with g++) */
    Boolean size: 1
    Character size: 1
    Wide character size: 2
    Short size: 2
    Integer size: 4
    Long size: 4
    Long Long size: 8
    Float size: 4
    Double size: 8
    Long Double size: 16 
    ```

# Exercise 4.7
> What does overflow mean? Show three expressions that will overflow.

## Solution
  
- **Wrapped around a value** <br>
It happens when the value stored in a variable is too large to be stored. In that case, the value wraps around to a negative number.
    ```c++
    short short_value = 32767; //the maximum value of short is 32767 
    cout << "The value before the addition: " << short_value << endl; 
    cout << "The value after the addition: " << ++short_value << endl; //adding 1 to a short type causes an overflow. The value is now -32768
    ```
    - ```c++
      //Output:
      The value before the addition: 32767
      The value after the addition: -32768
      ```
      
- **Operations on types that cannot handle the result** <br>
Let's assume that we have two variables of type int that we want to add together. However, the result will be too large to fit within that type. Next let's define a variable of type long long, which can hold the result, and initialize the result to it.
    ```c++
    int int_value1 = 1000000, int_value2 = 1000000; //two ints with a value of 1'000'000
    long long int_sum = int_value1 * int_value2;    //multiplication two integer, each equal to 1'000'000 causes an integer overflow. The product of ints is -727379968. This value is copied to the long long type
    long long long_value = 1000000000000;           //however, 1'000'000 * 1'000'000 itself fits withint the long long range
    cout << "The product of two ints: " << int_sum
         << " | The same number, but of type long long: " << long_value << endl;
    ```
    - ```c++
      //Output:
      The product of two ints: -727379968 | The same number, but of type long long: 1000000000000
      ```

- **Mixing unsigned and signed types** <br>
In expressions involving signed and unsigned types, the signed type is converted to an unsigned type.
    ```c++
    unsigned unsigned_int = 0;
    signed signed_int = -100;
    if (unsigned_int < signed_int) //the signed value of -100 is converted to a larger positive number. Using two signed types would return false
        cout << "Mixing signed and unsigned integers.";
    ```
    - ```c++
      //Output:
      Mixing signed and unsigned integers.
      ```

# Exercise 4.33
> Using Table 4.12 (p. 166) explain what the following expression does:

```c++
someValue ? ++x, ++y : --x, --y
```


## Solution

Since a conditional operator (`? :`) has a precedence level of `16`, and a comma operator (`,`) ranks the lowest, the expression is grouped as:
```c++
(someValue ? ++x, ++y : --x), --y
```
Notice that the last decrementation (`--y`) is outside the scope of the conditional operator. Presented in this way, the expression evaluates as follows:
- The true someValue leads to the incrementation of the variables x and y (`++x, ++y`) then the following expression is evaluated, in this case, the decrementation of `y` (`--y`). In the end, the value of `y` is unchanged, and the value of `x` is increased by `1`.
- On the other hand, the false someValue yields only the decrementation of `x` (`--x`) then the decrementation of `y` (`--y`).

# Exercise 4.24
> Our program ([2.22](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%204/04.22.md)) that distinguished between high pass, pass, and fail depended on the fact that the conditional operator is right associative. Describe how that operator would be evaluated if the operator were left associative

## Solution

Right associativity means that the code will grouped from right to left. These parentheses show the implicit evaluation order:
```c++
finalgrade = (grade > 90) ? "high pass" : ( (grade < 60) ? "fail" : "pass" ) ;
/*                                        /\                               /\                                   
 * These parentheses are added implicitly */

//Right associativity allows the second conditional operator to be evaluated correctly.
```
If the conditional operator were left-associative, the compiler would evaluate the expression as:
```c++
finalgrade = ( (grade > 90) ? "high pass" : (grade < 60) ) ? "fail" : "pass";
/*           /\                                          /\                                   
 * These parentheses would be added implicitly if the condition operator were left-associative */ 

//In this case, the first conditional operator has two different operand types: a const char* ("high pass") and a boolean (grade < 60). Such a difference causes a type mismatch error. 
```

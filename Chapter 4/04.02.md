# Exercise 4.2
> Using Table 4.12 (p. 166), parenthesize the following expressions to indicate the order in which the operands are grouped:

* `* vec.begin()`
* `vec.begin() + 1`

## Solution

* `* (vec.begin())` - Dereference of the return value of member function `begin()`.
* `(vec.begin()) + 1` - Add 1 to the return value of the member function `begin()`.

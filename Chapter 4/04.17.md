# Exercise 4.17
> Explain the difference between prefix and postfix increment

## Solution

Prefix increment (`++lvalue`) has lower precedence than postfix increment (`lvalue++`). Moreover, they behave differently:
- The prefix (`++lvalue`/`--lvalue`) returns the incremented (or decremented) `lvalue` in the same expression.
    ```c++
    int i = 0;
    cout << ++i; //prints the value 1
    cout << i;   //prints 1 as well
    ++i = 10;    //legal
    ```
- The postfix (`lvalue++`/`lvalue--`) returns a copy of the operand as the `rvalue`, and then increments (or decrements) the `lvalue`.
    ```c++
    int i = 0;
    cout << i++; //prints the value 0
    cout << i;   //prints the value 1 
    i++ = 10;    //semantic error
    ```
It's recommended to use prefix (`++lvalue`/`--lvalue`), when there is no need to use a copy of the operand before the increment (or decrement).

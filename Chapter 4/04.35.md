# Exercise 4.35
> Given the following definitions,

```c++
char cval;
int ival;
unsigned int ui;
float fval;
double dval;
```
identify the implicit type conversions, if any, taking place:
- `cval = 'a' + 3;`
- `fval = ui - ival * 1.0;`
- `dval = ui * fval;`
- `cval = ival + fval + dval;`

## Solution

- The expression `cval = 'a' + 3` converts the character literal `'a'` to `int`. The result of the addition is converted back to type `char` upon assignment to `cval`.
- The statement `fval = ui - ival * 1.0;` is grouped as: `fval = ui - (ival * 1.0);`, which means that `ival` is converted to `double`, and then the result of the multiplication (`ival * 1.0`) is used as the second operand of the subtraction (`ui - <double_result>`), where `ui` is also converted to `double`. Finally, the entire sub-expression `ui - ival * 1.0` is converted to `float` upon assignment.
- Mixing `unsigned int` and `float` in an arithmetic operation converts `ui` to `float`. The calculation yields a `float`, which the assignment to `dval` converts to `double`.
- The statement `cval = ival + fval + dval;` evaluates the addition from left to right, which means that `ival` is converted to `float`, and then the result is used in the addition with `dval`, where the resulting `float` is converted to `double` before adding `dval`. The result of the expression `ival + fval + dval` is converted to `char` as a result of being assigned to `cval`.

# Exercise 4.9
> Explain the behavior of the condition in the following if:

```c++
const char *cp = "Hello World";
if (cp && *cp)
```

## Solution

- The statement `const char *cp = "Hello World";` points to a read-only C-style string literal. This kind of pointer is handled differently. An expression of a pointer (without a dereference sign) as an operand with `std::cout` does not yield the memory address of this pointer, but the entire string literal itself.
    ```c++
    const int i = 12, *p1 = &i;
    cout << p1;  //prints a memory address -> 0xf4d1fffbac
    cout << *p1; //prints the value of int -> 12
    const char *cp = "Hello World";
    cout << cp;  //prints a string literal until the null terminator character -> Hello World
    cout << *cp; //prints the first character within the string literal -> H
    ```
- The compound expression placed inside the `if statement`, does two different things.
  - `cp` checks whether the pointer is valid (not nullptr). The pointer points to a string literal, so it is valid.
  - `*cp` checks whether the value which the pointer points to, differs from the value `0`. The result of `*cp` is the first character of the string literal e.g. `'H'`, which differs from `0`.
- Under the hood the statement `if (cp && *cp)` is equivalent to `if ("Hello World" != 0 && 'H' != 0)`.

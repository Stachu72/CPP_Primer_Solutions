# Exercise 4.5
> Determine the result of the following expressions.

- `-30 * 3 + 21 / 5`
- `-30 + 3 * 21 / 5`
- `30 / 3 * 21 % 5`
- `-30 / 3 * 21 % 4`

## Solution

- `-30 * 3 + 21 / 5` = `(-30 * 3) + (21 / 5)` = `-90 + 4` = `-86`
- `-30 + 3 * 21 / 5` = `-30 + ((3 * 21) / 5)` = `-30 + (63 / 5)` = `-30 + 12` = `-18`
- `30 / 3 * 21 % 5` = `((30 / 3) * 21) % 5` = `(10 * 21) % 5` = `210 % 5` = `0`
- `-30 / 3 * 21 % 4` = `((-30 / 3) * 21) % 4` = `(-10 * 21) % 4` = `-210 % 4` = `-2`

* **Code:**
    ```c++
    #include <iostream>
    using std::cout;
    int main() {
       cout << -30 * 3 + 21 / 5 << " | "
            << -30 + 3 * 21 / 5 << " | "
            <<  30 / 3 * 21 % 5 << " | "
            << -30 / 3 * 21 % 4; //Note: The modulus (%)operator takes the sign of the left-hand operand. For (-m)%n the result will be <=0
       return 0;
    }
    ```

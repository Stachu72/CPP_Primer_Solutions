# Exercise 4.38
> Explain the following expression:

```c++
double slope = static_cast<double>(j/i);
```

## Solution

In this case, the named cast is evaluated right after the division of the two ints. Thus, the result of the operation (`j/i`) still remains an `int`, and the precision is lost. In order to get the result as `double` the named cast requires being used with one of the operand:
```c++
int j = 11, i = 2;
double slope = static_cast<double>(j/i); //The result is 5
double slope = static_cast<double>(j)/i; //The result is 5.5
double slope = j/static_cast<double>(i); //The result is 5.5
```

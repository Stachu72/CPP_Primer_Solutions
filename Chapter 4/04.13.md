# Exercise 4.13
> What are the values of i and d after each assignment?

```c++
int i; double d;
d = i = 3.5;
i = d = 3.5;
```

## Solution

```c++
int i; double d;
d = i = 3.5; //i = 3.5 -> the value is truncated -> i = 3 | d = i(i.e. 3)
i = d = 3.5; //d = 3.5 (d is a double type: OK) | i = d(i.e. 3.5) -> the value is truncated -> i = 3(i.e. truncated d)
```

# Exercise 4.10
> Write the condition for a while loop that would read ints from the standard input and stop when the value read is equal to 42.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cin;
  int main() {
      int user_input;
      while (cin >> user_input && user_input != 42) { //checks if the input data is valid and not equal to 42
          //Do something...
      }
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    2
    40
    12
    0
    42 //(the while loop ends here)
    //Output: (No output)
    ```

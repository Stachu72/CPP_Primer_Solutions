# Exercise 4.32
> Explain the following loop.

```c++
constexpr int size = 5;
int ia[size] = { 1,2,3,4,5 };
for (int *ptr = ia, ix = 0; ix != size && ptr != ia+size; ++ix, ++ptr) {
    /* ... */
}
```

## Solution

- The loop initializes two variables within a loop scope:
  - The integer variable `ix` with the value `0`.
  - The pointer to int (`ptr`) holding the address of the first element in the array `ia`.
- The loop uses the logical AND operator (`&&`) to check whether the condition is true, which means that both expressions of the logical AND have to be true in order to execute the loop body:
  - `ix != size` > First checks whether the index variable (`ix`) has not reached the end index of the array (`ia`).
  - `ptr != ia+size` > Then checks whether the pointer to int points to the past-the-end address.
- After every successful iteration, the loop increments the index variable (`++ix`) and advances the pointer (`++ptr`).

Summary: The loop traverses the array using both an index (`ix`) and a pointer (`ptr`) simultaneously. Note that both condition checks are redundant. Either one alone would be sufficient to prevent going out of bounds.

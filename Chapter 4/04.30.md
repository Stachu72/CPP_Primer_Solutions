# Exercise 4.30
> Using Table 4.12 (p. 166), parenthesize the following expressions to match the default evaluation:

- `sizeof x + y`
- `sizeof p->mem[i]`
- `sizeof a < b`
- `sizeof f()`

## Solution

- `sizeof x + y` > `(sizeof x) + y`
- `sizeof p->mem[i]` > `sizeof ((p->mem)[i])`
- `sizeof a < b` > `(sizeof a) < b`
- `sizeof f()` > `sizeof (f())`

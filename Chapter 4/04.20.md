# Exercise 4.20
> Assuming that iter is a vector<string>::iterator, indicate which, if any, of the following expressions are legal. Explain the behavior of the legal expressions and why those that aren’t legal are in error.

- `*iter++;`
- `(*iter)++;`
- `*iter.empty()`
- `iter->empty();`
- `++*iter;`
- `iter++->empty();`

## Solution

- `*iter++;` - dereferences `iter`, then increments the iterator. **Correct**.
- `(*iter)++;` - dereferences `iter`, then increments the string pointed to by the iterator. **Invalid**, there is no increment operator (`++`) for a string type.
- `*iter.empty()` - calls the member the function `empty()` on the iterator, then dereferences it. **Invalid**, there is no function `empty()` for the iterator.
- `iter->empty();` - calls the member the function `empty()` on the string pointed to by the iterator. **Correct**.
- `++*iter;` - increments the string pointed to by the iterator. **Invalid**, there is no increment operator (`++`) for a string type.
- `iter++->empty();` - calls the member function `empty()` on the string pointed to by the iterator, then increments the iterator. **Correct**.

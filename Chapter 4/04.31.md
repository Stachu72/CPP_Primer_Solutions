# Exercise 4.31
> The program in this section used the prefix increment and decrement operators. Explain why we used prefix and not postfix. What changes would have to be made to use the postfix versions? Rewrite the program using postfix operators.

- **Mentioned program:**
```c++
vector<int>::size_type cnt = ivec.size();
//assign values from size...1 to the elements in ivec
for(vector<int>::size_type ix = 0; ix != ivec.size(); ++ix, --cnt)
    ivec[ix] = cnt;
```

## Solution

- **Code:**
    ```c++
    vector<int>::size_type cnt = ivec.size();
    //assign values from size...1 to the elements in ivec
    for(vector<int>::size_type ix = 0; ix != ivec.size(); ix++, cnt--) //changing from prefix to postfix operators did not alter the result
        ivec[ix] = cnt;
    ```

After changing the prefix operators to the postfix operators, the program's behavior did not change. However, the main difference lies in performance. The postfix operators save a copy of the variable, modify the variable, and then return the copy. In this case, this behavior is not needed.

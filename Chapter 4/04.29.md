# Exercise 4.29
> Predict the output of the following code and explain your reasoning. Now run the program. Is the output what you expected? If not, figure out why.

```c++
int x[10]; int *p = x;
cout << sizeof(x)/sizeof(*x) << endl;
cout << sizeof(p)/sizeof(*p) << endl;
```

## Solution

- The statement `cout << sizeof(x)/sizeof(*x) << endl;` always prints the output `10`. That's because the size of the ten-element array (`int x[10]`) is divided by the size of one of its elements (`int`). This is an example of a way to calculate array size.
- The second statement `cout << sizeof(p)/sizeof(*p) << endl;` differs on different platforms. For example, on a 32-bit system, a pointer is 4 bytes, but on a 64-bit system, it is 8 bytes. That means:
  ```c++
  /* On a 32-bit system: */
  // sizeof(p) = 4 bytes and sizeof(*p) = 4 bytes
  // sizeof(p)/sizeof(*p) = 4/4 = 1 
  
  /* On a 64-bit system: */
  // sizeof(p) = 8 bytes and sizeof(*p) = 4 bytes
  // sizeof(p)/sizeof(*p) = 8/4 = 2 
  ```

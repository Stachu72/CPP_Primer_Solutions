# Exercise 4.15
> The following assignment is illegal. Why? How would you correct it?

```c++
double dval; int ival; int *pi;
dval = ival = pi = 0;
```

## Solution

The assignment is illegal, because a pointer cannot be implicitly converted to an `int`. It is a requirement for multiple assignment: <br>
_Each object in a multiple assignment must have the same type as its right-hand
neighbor or a type to which that neighbor can be converted._ <br>
Move the pointer to another line:
```c++
double dval; int ival; int *pi;
pi = 0;          //pi is now a nullptr
dval = ival = 0; //ival = 0 | dval = ival
```

# Exercise 4.22
> Extend the program that assigned high pass, pass, and fail grades to also assign low pass for grades between 60 and 75 inclusive. Write two versions: One version that uses only conditional operators; the other should use one or more if statements. Which version do you think is easier to understand and why?

- **Mentioned code:**
    ```c++
    finalgrade = (grade > 90) ? "high pass"
                              : (grade < 60) ? "fail" : "pass";
    ```

## Solution

- **Conditional operator:**
  ```c++
  finalgrade = (grade > 90) ? "high pass"           //grade above 90 gets high pass,
             : (grade > 75) ? "pass"                //76 to 90 gets a regular pass,
             : (grade >= 60) ? "low pass" : "fail"; //below 60 fails; 60 to 75 gets a low pass
  ```

- **If statement:**
  ```c++
  if (grade > 90)               //grade above 90 gets high pass,
      finalgrade = "high pass";
  else if (grade > 75)          //76 to 90 gets a regular pass,
      finalgrade = "pass";
  else if (grade >= 60)         //60 to 75 gets a low pass
      finalgrade = "low pass";
  else                          //below 60 fails
      finalgrade = "fail";
  ```
  
The conditional operator (`? :`) should be used only with simple expression and has particular requirements. On the other hand, an if-else statement may be used with complex statements and perform various operations within each branch. I think in this case readability is subjective, but my personal choice would be the conditional operator (`? :`), due to its conciseness.

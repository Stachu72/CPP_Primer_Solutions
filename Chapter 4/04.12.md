# Exercise 4.12
> Assuming i, j, and k are all ints, explain what i != j < k means.

## Solution

The `<` operator has higher precedence than the `!=` operator, which means that the subexpression `j < k` is evaluated before the inequality check. The expression `j < k` yields `true` only if `k` is greater than `j` and false otherwise. Then this result is promoted from boolean to int (where `false = 0`, and `true = 1`). The first subexpression is equivalent to `i != 1`, or `i != 0`.

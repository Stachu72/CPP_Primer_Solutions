# Exercise 4.18
> What would happen if the while loop on page 148 that prints the elements from a vector used the prefix increment operator?

- **The loop:**
  ```c++
  auto pbeg = v.begin();
  //print elements up to the first negative value
  while (pbeg != v.end() && *pbeg >= 0)
  cout << *pbeg++ << endl; //print the current value and advance pbeg
  ```

## Solution

Prefix unary operators have right-to-left associativity, which means that the expression `*++pbeg` is evaluated as: `*(++pbeg)`. First, it increments the iterator by 1, and then dereferences the iterator at its new position. <br> 
- In this scenario:
  - The loop skips the first element (`v.begin()`) and starts printing from index 1.
  - If a negative number is encountered, the loop will print that negative value before stopping.
  - If all elements are non-negative, the loop will increment past the last element and attempt to dereference `v.end()`, causing undefined behavior.

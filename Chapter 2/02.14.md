# Exercise 2.14
> Is the following program legal? If so, what values are printed?

```c++
int i = 100, sum = 0;
for (int i = 0; i != 10; ++i)
    sum += i;
std::cout << i << " " << sum << std::endl
```

## Solution

It's valid but not recommended. The variable `i` created in `for` statement overshadows the variable of the same name outside of it. The loop operates on the inner variable, but after it finishes, the previously created variable `i` is displayed.

- Output: <br>
`100 45`

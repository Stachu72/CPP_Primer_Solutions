# Exercise 2.10
> What are the initial values, if any, of each of the following variables?

```c++
std::string global_str;
int global_int;
int main()
{
    int local_int;
    std::string local_str;
}
```

## Solution

Answers are in comments

```c++
std::string global_str; //empty string i.e. ""
int global_int; //global variable = 0
int main()
{
    int local_int; //located at the block scope, undefined value
    std::string local_str; //string is not a bulilt-in type, so block scope does not apply here. Result: empty string.
}
```

# Exercise 2.11
> Explain whether each of the following is a declaration or a definition:

(a) `extern int ix = 1024;` <br>
(b) `int iy;` <br>
(c) `extern int iz;`

## Solution

(a) Using `extern` along with the initialization causes it to stop working. It's the definition. <br>
(b) Simple definition. <br>
(c) Using `extern` without initialization. Declaration.

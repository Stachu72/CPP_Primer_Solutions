# Exercise 2.24
> Why is the initialization of p legal but that of lp illegal?

```c++
int i = 42;
void *p = &i;
long *lp = &i;
```

## Solution

In c++ a pointer type must match the type of the pointed object it points to. One of the two exceptions is the `void*` type, which can point to any other type but with certain restrictions. For this reason, the expression `void* = int` is valid, while `long* = int` is not.

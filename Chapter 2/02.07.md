# Exercise 2.7
> What values do these literals represent? What type does each have?

(a) `Who goes with F\145rgus?\012` <br>
(b) `3.14e1L` <br>
(c) `1024f` <br>
(d) `3.14L`

## Solution

(a) `Who goes with Fergus?` - string <br>
(b) `31.4` - long double <br>
(c) `1024` - Should have added a `.` sign before the `f`. Then it would be `float`. <br>
(d) `3.14` - long double

# Exercise 2.29
> Using the variables in the previous exercise [(2.28)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%202/02.28.md), which of the following assignments are legal? Explain why.

(a) `i = ic;` <br>
(b) `p1 = p3;` <br>
(c) `p1 = &ic;` <br>
(d) `p3 = &ic;` <br>
(e) `p2 = p1;` <br>
(f) `ic = *p3;`

## Solution

(a) `i = ic` - `int = const int` | Correct <br>
(b) `p1 = p3` - `int* = const int *const` | Incorrect - `p3` is a top-level const <br>
(c) `p1 = &ic` - `int* = (&) const int` | Incorrect - `ic` is a low-level const, `p1` require it too, <br>
(d) `p3 = &ic` - `const int *const = (&) const int` | Incorrect - `p3` is top-level const and cannot be changed after the initialization, <br>
(e) `p2 = p1` - `int *const = *int` | Incorrect - `p2` cannot be changed after the initialization,
(f) `ic = *p3` - `const int = (*) const int *const` | Incorrect - `ic` cannot be changed after the initialization.

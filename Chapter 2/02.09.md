# Exercise 2.9
> Explain the following definitions. For those that are illegal, explain what’s wrong and how to correct it.

(a) `std::cin >> int input_value;` <br>
(b) `int i = { 3.14 };` <br>
(c) `double salary = wage = 9999.99;` <br>
(d) `int i = 3.14;`

## Solution

(a) `input_value` should be defined before using `std::cin`, correction:
```c++
int input_value;
std::cin >> input_value;
``` 
<br>

(b) `int i = { 3.14 };` contains a list initialization, which results in lost information. Change `i` to a floating-point type, or delete braces:
```c++
float i = { 3.14 };
int i = 3.14; //the value will be truncated
```
<br>

(c) `double salary = wage = 9999.99;` - the `wage` has not been declared. Here are a few ways to fix this:
```c++
double salary = 9999.99, wage = salary; //single line option

double wage = 9999.99; //two lines span option
double salary = wage;  
```
<br>

(d) `int i = 3.14;` - valid, but just like before, the value will be truncated.

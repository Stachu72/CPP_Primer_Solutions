# Exercise 2.33
> Using the variable definitions from this section, determine what happens in each of these assignments:


```c++
a = 42;
b = 42;
c = 42;
d = 42;
e = 42;
g = 42;
```
## Solution

- Definitions from the section:
```c++
int i = 0, &r = i;
auto a = r;
const int ci = i, &cr = ci;
auto b = ci;
auto c = cr;
auto d = &i;
auto e = &ci;
auto &g = ci;
```

- Solution:
```c++
a = 42; // Regular assigment: (int) a = 42
b = 42; // Regular assigment: (int) b = 42 
c = 42; // Regular assigment: (int) c = 42
d = 42; // Error: attempt to assign an int value to a pointer variable | (int*) d = 42
e = 42; // Error: attempt to assign an int value to a pointer variable | (const int*) e = 42
g = 42; // Error: attempt to assign to a reference to const | (const int&) g = 42
```

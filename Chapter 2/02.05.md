# Exercise 2.5
> Determine the type of each of the following literals. Explain the differences among the literals in each of the four examples:

(a) `’a’, L’a’, "a", L"a"` <br>
(b) `10, 10u, 10L, 10uL, 012, 0xC` <br>
(c) `3.14, 3.14f, 3.14L` <br>
(d) `10, 10u, 10., 10e-2`

## Solution

(a) `'a'` - character, `L'a'` - wide character, `"a"` - string, `L"a"` - wide string. <br>
(b) `10` - int, `10u` - unsigned int, `10L` - long, `10uL` - unsigned long, `012` - int, `0xC` - int. <br>
(c) `3.14` - double, `3.14f` - float, `3.14L` - long double, <br>
(d) `10` - int, `10u` - unsigned int, `10.` - double, `10e-2` - double.

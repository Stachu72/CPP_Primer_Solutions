# Exercise 2.25
> Determine the types and values of each of the following variables.

(a) `int* ip, i, &r = i;` <br>
(b) `int i, *ip = 0;` <br>
(c) `int* ip, ip2;`

## Solution

If these definitions are located within the body of a function, class, or structure, then: <br>
(a) `int* ip` = undefined, `int i` = undefined, `int &r = i` = undefined <br>
(b) `int i` = undefined, `int *ip = 0` = 0 / nullptr <br>
(c) `int *ip` = undefined, `int ip2` = undefined.

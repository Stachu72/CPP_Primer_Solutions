# Exercise 2.17
> What does the following code print?

```c++
int i, &ri = i;
i = 5; ri = 10;
std::cout << i << " " << ri << std::endl;
```

## Solution

- **Output:**
```c++
10 10
```

- **Answer:** <br>
In the second line `r1 = 10` overrides the variable `i` setting its value to `10`. This can be interpreted as `i = 5; i = 10;`.

# Exercise 2.38
> Describe the differences in type deduction between decltype and auto. Give an example of an expression where auto and decltype will deduce the same type and an example where they will deduce differing types.

## Solution

|                                          | auto | decltype |
|------------------------------------------|------|----------|
| **Takes references into accounts?**      | No   | Yes      |
| **Takes top-level const into accounts?** | No   | Yes      |
| **Decucates type from an expression?**   | No   | Yes      | 

(A) `decltype` differ from `auto` in that a variable defined as a reference is not treated as a synonym for the object to which it refers: <br>
```c++
int a = 10, &b = a;
auto ab = b;         // ab is of int type
decltype(b) db = b;  // db is of int& type
```
Both `ab` and `db` infer the type of variable `b`, **auto** returns the type to which `b` refers (`int a`), and **decltype** returns the type of `b` itself (`int &b`). <br>

<br>

(B) Top-level consts are returned by `decltype` in the same way as low-level const. However `auto` generally omits top-level const:
```c++
const int i = 10;
auto a = i;         // a is of int type
decltype(i) b = 0;  // b is of CONST int type

const int *const x = &i;
auto c = x;               // c is a pointer to const int
decltype(x) d = nullptr;  // d is a CONST pointer to const int
```

<br>

(C) In addition, `decltype` can infer type from an expression:
```c++
int a = 10, b = 20;
decltype(a) c = 0;    // x is of int type                               | int c = 0
decltype(a - b) d = 0 // subtraction yields an int                      | int d = 0
decltype(a + b) e = 0 // addition yields an int                         | int e = 0
decltype(a = b) f = b // assigment yields a reference type              | int& f = b
decltype((a)) g = b   // double parentheses yields a reference type     | int& g = b
```

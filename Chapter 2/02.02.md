# Exercise 2.2
> To calculate a mortgage payment, what types would you use for the rate, principal, and payment? Explain why you selected each type.

## Solution

It depends on the size of the mortgage payment; the safest choice would be:
- For an interest rate `float` can be used, since it is a small floating-point number,
- A principal amount may vary, so `double` should handle this without any loss of precision,
- In some cases, the `float` type would suffice for the payment, but this is a general consideration. Therefore, we choose the same type as above - `double`.

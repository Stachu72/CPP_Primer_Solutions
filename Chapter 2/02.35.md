# Exercise 2.35
> Determine the types deduced in each of the following definitions. Once you’ve figured out the types, write a program to see whether you were correct.

```c++
const int i = 42;
auto j = i; const auto &k = i; auto *p = &i;
const auto j2 = i, &k2 = i;
```

## Solution

- **Predictions:**
```c++
const int i = 42;
auto j = i; // int
const auto &k = i; // const int&
auto *p = &i; // const int*
const auto j2 = i, &k2 = i; // const int, const int&
```

- **Code:**
```c++
int main() {
    const int i = 42;
    auto j = i; const auto &k = i; auto *p = &i;
    const auto j2 = i, &k2 = i;
    j = 1;  // regular assigment
    k = 2;  //Error: reference to const
    p = 3;  //Error: pointer to const
    j2 = 4; //Error: const int
    k2 = 5; //Error: reference to const
}
```

- **Summary:**
My predictions were correct.

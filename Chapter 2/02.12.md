# Exercise 2.12
> Which, if any, of the following names are invalid?

(a) `int double = 3.14;` <br>
(b) `int _;` <br>
(c) `int catch-22;` <br>
(d) `int 1_or_2 = 1;` <br>
(e) `double Double = 3.14;`

## Solution

(a) Using the word `double` as a variable name cause an error, <br>
(b) valid,
(c) as in point (a), the word `catch` is a keyword and **cannot** be used in a variable name, <br>
(d) the variable names **cannot** begin with numbers,  <br>
(e) capital letters makes the keyword `double` into the standalone word `Double`. This is correct, but not recommended.

# Exercise 2.19
> Explain the key differences between pointers and references.

## Solution

|                                         | Reference                                             | Pointer                                               |
|-----------------------------------------|-------------------------------------------------------|-------------------------------------------------------|
| **It is an object?**                    | No                                                    | Yes                                                   |
| **Can be pointed by pointer?**          | No                                                    | Yes                                                   |
| **Must be initialized?**                | Yes                                                   | Only if `non-const Top-Level`                         |
| **Can be changed after initializaton?** | No                                                    | Only if `non-const Top-Level`                         |
| **Regular statement**                   | *Type* **&** *Name* **=** *refered object*;           | *Type* __*__ *Name*;                                  |
| **Low-Level const statement**           | **const** *Type* **&** *Name* **=** *refered object*; | **const** *Type* __*__ *Name* **=** *pointed object*; |
| **Top-Level const statement**           | -                                                     | *Type* __* const__ *Name* **=** *pointed object*;     |

# Exercise 2.28
> Explain the following definitions. Identify any that are illegal.

(a) `int i, *const cp;` <br>
(b) `int *p1, *const p2;` <br>
(c) `const int ic, &r = ic;` <br>
(d) `const int *const p3;` <br>
(e) `const int *p;`

## Solution

(a)
- `int i` - Integer,
- `*const cp` = `int *const cp` - invalid, top-level const pointer require the initialization.

(b)
- `int *p1` - Pointer to integer,
- `*const p2` = `int *const c2` - invalid, the definition require the initialization. 

(c)
- `const int ic` - Invalid, top-level const variable require the initialization,
- `&r = ic` = `const int &r = ic` - reference to const int `ic`.

(d)
- `const int *const p3;` - Invalid, top-level const variable require the initialization,

(e)
- `const int *p;` - Pointer to const int.

# Exercise 2.1
> What are the differences between int, long, long long, and short? Between an unsigned and a signed type? Between a float and a double?

## Solution

* *What are the differences between `int`, `long`, `long long`, and `short`?* <br>

These types differ in the size of bits, i.e, the range of numbers they support (see the table below)

| Type        | Minimum size     | Additional               |
|-------------|------------------|--------------------------|
| `short`     | at least 16 bits |                          |
| `int`       | at least 16 bits | not smaller than `short` |
| `long`      | at least 32 bits | not smaller than `int`   |
| `long long` | at least 64 bits | not smaller than `long`  |

* *What are the differences between an `unsigned` and a `signed` type?* <br>

The main difference between these two keywords is whether the number can be positive. `Unsigned` types **cannot** be negative values, but they can hold larger positive numbers. `Signed` sacrifice  the positive values in favor of the negative ones.

| Type           | Signed values                   | Unsigned values          |
|----------------|---------------------------------|--------------------------|
| `16 bit short` | -32,768 to 32,767               | 0 to 65,535              |
| `32 bit int`   | -2,147,483,648 to 2,147,483,647 | 0 to 4,294,967,295       |

* *What are the differences between a `float` and a `double`?* <br>

Both types are differ from standard integer types because they store floating-point numbers. The `double` type has twice the bit width of `float` and does not cause precision errors when dealing with large numbers. The `float` type has a precision of 7 decimal places, while the `double` has a precision of 15.

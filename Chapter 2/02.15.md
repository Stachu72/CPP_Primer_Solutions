# Exercise 2.15
> Which of the following definitions, if any, are invalid? Why?

(a) `int ival = 1.01;` <br>
(b) `int &rval1 = 1.01;` <br>
(c) `int &rval2 = ival;` <br>
(d) `int &rval3;`

## Solution

(a) The value `1.01` is a double type and will be truncated to `1`. The initialization is correct, <br>
(b) Invalid. A regular reference **cannot** be initialized with a literal value. Add the `const` keyword before the reference, <br>
(c) Valid, <br>
(d) A reference **must have** a initialization, because it is not an object.

# Exercise 2.34
> Write a program containing the variables and assignments from the previous exercise [(2.33)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%202/02.33.md). Print the variables before and after the assignments to check whether your predictions in the previous exercise were correct. If not, study the examples until you can convince yourself you know what led you to the wrong conclusion.

## Solution

- **Code**:

```c++
#include <iostream>

int main() {
    int i = 0, &r = i;
    auto a = r;
    const int ci = i, &cr = ci;
    auto b = ci;
    auto c = cr;
    auto d = &i;
    auto e = &ci;
    auto &g = ci;
    std::cout << "A: " << a << " B: " << b << " C: " << c << " D: " << *d << " E: " << *e << " G: " << g << std::endl;
    a = 42; b = 42; c = 42; // Errors: d = 42; e = 42; g = 42;
    std::cout << "A: " << a << " B: " << b << " C: " << c << " D: " << *d << " E: " << *e << " G: " << g << std::endl;
}
```

- **Output**:
```c++
A: 0 B: 0 C: 0 D: 0 E: 0 G: 0
A: 42 B: 42 C: 42 D: 0 E: 0 G: 0
```

- **Summary**:
My predictions were correct. a, b and c are of type int and are assigned the value 42. d, e and g cannot hold values of type int.

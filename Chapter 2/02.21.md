# Exercise 2.21
> Explain each of the following definitions. Indicate whether any are illegal and, if so, why.

`int i = 0;` <br>
(a) `double* dp = &i;` <br>
(b) `int *ip = i;` <br>
(c) `int *p = &i;` <br>

## Solution

(a) The compiler does not allow a `double*` pointer to point to an `int` object, <br>
(b) Invalid. The variable `i` is not preceded by the **&** reference symbol, <br>
(c) Valid.

# Exercise 2.16
> Which, if any, of the following assignments are invalid? If they are valid, explain what they do.
 
`int i = 0, &r1 = i; double d = 0, &r2 = d;` <br>
(a) `r2 = 3.14159;` <br>
(b) `r2 = r1;` <br>
(c) `i = r2;` <br>
(d) `r1 = d;`

## Solution

(a) The underlying object of `&r2` is `d` and it is receiving the value `3.14158`, <br>
(b) `r2 = r1` implies indirectly that `d = i`, which means that the variable `d` will take the value `0.0`, <br>
(c) `i = r2;` is equivalent to `i = d` i.e. the variable `i` takes the value `0` and (potentially) will be truncated, <br>
(d) Same as above but indirectly with regard to`i` and directly with regard to `d`.

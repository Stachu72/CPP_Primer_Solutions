# Exercise 2.18
> Write code to change the value of a pointer. Write code to change the value to which the pointer points.

```c++
int i, &ri = i;
i = 5; ri = 10;
std::cout << i << " " << ri << std::endl;
```

## Solution

```c++
#include <iostream>

int main()
{
    int i = 10, *p1 = &i, j = 20;
    p1 = &j; // Changing the underlying object. Now p1 points to j variable
    std::cout << "New pointing object value: " << *p1 << std::endl;
    *p1 = 30; // Changing the pointed object value. I.e. j = 30
    std::cout << "Pointed object value after indirect change: " << *p1 << std::endl;
}
```

# Exercise 3.18
> Is the following program legal? If not, how might you fix it?

```c++
vector<int> ivec;
ivec[0] = 42;
```
## Solution

The vector `ivec`, which holds integer values but contains no elements, and in the second line an attempt is made to change the first element of the vector to the value `42`. You cannot change an element that does not exist. The result is **undefined**. <br>

**How to fix it?** <br>
1. Do not try to access a non-existing element - remove the second line (`ivec[0] = 42;`). 
2. If the first element is supposed to take the value (in this case) `42`, there are two ways how to solve this problem: <br>
(a) Initialize the vector by adding at least one element to it (e.g. `vector<int> ivec(1)`), and then change its value. <br>
(c) Initialize the vector with a value `42` (e.g. `vector<int> ivec = { 42 }`). <br>
(b) If the size of the vector is unknown at initialization, simply add the first element with a value `42` at runtime (`ivec.push_back(42)`).

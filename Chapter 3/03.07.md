# Exercise 3.7
> What would happen if you define the loop control variable in the previous exercise [(3.6)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%203/03.06.md) as type char? Predict the results and then change your program to use a char to see if you were right.

## Solution

If we change `auto &letter : ..` to a regular `char`, i.e. `char letter : ..`. We would not be able to change the value of a string variable, as we are not operate on characters within the string. On the other hand, if we were to add a reference notation, i.e. `char &letter : ..`, everything would work perfectly fine.

- **Changed program**:

```c++
#include <iostream>
using std::cin; using std::cout; using std::endl; using std::string; using std::getline;

int main()
{
    cout << "Enter a sentence: ";
    string userInput;
    getline(cin, userInput);
    for (char &letter: userInput) { //Do not forget that the char is a reference type!
        letter = 'X';
    }
    cout << "Your sentence in which every character has been replaced by an X: " << userInput << endl;
}
```

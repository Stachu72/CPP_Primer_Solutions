# Exercise 3.7
> What would happen if you define the loop control variable in the previous exercise [(3.6)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%203/03.06.md) as type char? Predict the results and then change your program to use a char to see if you were right.

## Solution

If we replaced `auto &letter : ..` with a plain `char`, i.e. `char letter : ..`, we wouldn't be able to modify the string's elements since we would be working with copies rather than the characters within the string itself. However, if we passed it by reference as `char &letter : ..`, everything would work flawlessly.

- **The program with a plain `char`**:
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl;
    using std::string; using std::getline;
    int main() {
        cout << "Enter a sentence: ";
        string userInput;
        getline(cin, userInput);
        for (char letter : userInput) //using a plain char does't let change the string elements
            letter = 'X';
        cout << "Your sentence, which has been changed: " << userInput << endl;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    Hello, World!
    //Output:
    Your sentence, which has been changed: Hello, World!
    ```

- **The program with a `reference to char`**:
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl;
    using std::string; using std::getline;
    int main() {
        cout << "Enter a sentence: ";
        string userInput;
        getline(cin, userInput);
        for (char &letter : userInput) //the code behaves the same as in 3.6
            letter = 'X';
        cout << "Your sentence, which has been changed: " << userInput << endl;
    }
    ```
    - Input/Output:
      ```c++
      //Input:
      Hello, World!
      //Output:
      Your sentence, which has been changed: XXXXXXXXXXXXX
      ```

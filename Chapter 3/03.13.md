# Exercise 3.13
> How many elements are there in each of the following vectors? What are the values of the elements?

(a) `vector<int> v1;` <br>
(b) `vector<int> v2(10);` <br>
(c) `vector<int> v3(10, 42);` <br>
(d) `vector<int> v4{10};` <br>
(e) `vector<int> v5{10, 42};` <br>
(f) `vector<string> v6{10};` <br>
(g) `vector<string> v7{10, "hi"};`

## Solution

| Vector                             | Size | Element values                       |
|------------------------------------|------|--------------------------------------|
| (a) `vector<int> v1;`              | 0    | No elements                          |
| (b) `vector<int> v2(10);`          | 10   | Ten `ints` with value `0`            |
| (c) `vector<int> v3(10, 42);`      | 10   | Ten `ints` with value `42`           |
| (d) `vector<int> v4{10};`          | 1    | Single `int` with value `10`         |
| (e) `vector<int> v5{10, 42};`      | 2    | Two `ints` with values `10` and `42` |
| (f) `vector<string> v6{10};`       | 10   | Ten empty `strings`                  |
| (g) `vector<string> v7{10, "hi"};` | 10   | Ten `strings` with value `"hi"`      |

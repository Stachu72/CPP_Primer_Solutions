# Exercise 3.36
> Write a program to compare two arrays for equality. Write a similar program to compare two vectors.

## Solution

- _Write a program to compare two arrays for equality._:
  ```c++
  #include <iostream>
  #include <iterator>
  using std::cout; using std::endl;
  using std::begin; using std::end;
  int main() {
      int arr1[5] = { 0, 1, 2, 3, 4 };
      int arr2[5] = { };
      int *beg1 = begin(arr1), *end1 = end(arr1); //begin and end points of arr1
      int *beg2 = begin(arr2), *end2 = end(arr2); //begin and end points of arr2
      if (end1 - beg1 != end2 - beg2) { //checks whether the arrays are of different sizes
          cout << "The given arrays are different.";
          return 0;
      }
      for (int *p1 = beg1, *p2 = beg2 ; p1 != end1 && p2 != end2; ++p1, ++p2) { //iterates through the elements of the array one by one
          if (*p1 != *p2) { //checks whether the element value in both arrays are different from each other
              cout << "The given arrays are different.";
              return 0;
          }
      }
      cout << "The given arrays are the same.";
      return 0;
  }
  ```
  - Input/Output:
    - ```c++

      The given arrays are different.
      ```
    - ```c++
      //Output: (for arr1[5] = { 0, 1, 2, 3, 4 } and arr2[7] = { 0, 1, 2, 3, 4 })
      The given arrays are different.
      ```
    - ```c++
      //Output: (for arr1[5] = { 0, 1, 2, 3, 4 } and arr2[5] = { 0, 1, 2, 3, 4 })
      The given arrays are the same.
      ```

- _Write a similar program to compare two vectors._:
  ```c++
  #include <iostream>
  #include <vector>
  using std::cout;
  using std::vector;
  int main() {
      vector<int> ivec1 = { 0, 1, 2, 3, 4 };
      vector<int> ivec2 = { };
      if (ivec1 == ivec2)  //checks whether the vectors are the same
          cout << "The given vectors are the same.";
      else
          cout << "The given vectors are different.";
      return 0;
  }
  ```
  - Input/Output:
    - ```c++
      //Output: (for ivec1 = { 0, 1, 2, 3, 4 } and ivec2 = { })
      The given vectors are different.
      ```
    - ```c++
      //Output: (for ivec1 = { 0, 1, 2, 3, 4 } and ivec2 = { 0, 1, 2, 3, 0 })
      The given vectors are different.
      ```
    - ```c++
      //Output: (for ivec1 = { 0, 1, 2, 3, 4 } and ivec2 = { 0, 1, 2, 3, 4 })
      The given vectors are the same.
      ```

# Exercise 3.26
> In the binary search program on page 112, why did we write `mid = beg + (end - beg) / 2;` instead of `mid = (beg + end) /2;`?


- **A fragment of the program on page 112:**
    ```c++
    auto beg = text.begin(), end = text.end();
    auto mid = text.begin() + (end - beg)/2; //original midpoint
    ```

## Solution

According to **table 3.7** on page 111, there is no operation for adding two iterators. Subtracting two iterators returns a `difference_type`, which can be used in an addition operation with an iterator.

- `auto mid = iterator + (difference type | iterator - iterator) / 2` = ok.
- `auto mid = (iterator + iterator) / 2` = invalid.

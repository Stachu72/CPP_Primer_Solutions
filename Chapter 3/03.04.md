# Exercise 3.4
> Write a program to read two strings and report whether the strings are equal. If not, report which of the two is larger. Now, change the program to report whether the strings have the same length, and if not, report which is longer.

## Solution

- _Write a program to read two strings and report whether the strings are equal. If not, report which of the two is larger._:
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl;
    using std::string;
    int main() {
        string s1, s2;
        cin >> s1 >> s2; //get two strings from the user
        if (s1 == s2)  //check whether both strings have the same size and the same elements (are equal)
            cout << "The given strings are identical." << endl;
        else {
            if (s1 > s2) //check whether the first letter that differs between these two strings, in the first string, is larger than in the second
                cout << "The first string is larger." << endl;
            else 
                cout << "The second string is larger." << endl;
        }
    }
    ```
  - Input/Output:
    - ```c++
      //Input:
      abc abc
      //Output:
      The given strings are identical.
      ```
    - ```c++
      //Input:
      ab abc
      //Output:
      The second string is larger.
      ```
    - ```c++
      //Input:
      abd abc
      //Output:
      The first string is larger.
      ```
    - ```c++
      //Input: (two empty strings)
     
      //Output:
      The given strings are identical.
      ```

- _[...] change the program to report whether the strings have the same length, and if not, report which is longer._:
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl;
    using std::string;
    int main() {
        string s1, s2;
        cin >> s1 >> s2; //get two strings from the user
        if (s1.size() == s2.size()) //check whether both strings have the same size
            cout << "The given string are the same length." << endl;
        else {
            if (s1.size() > s2.size()) //in the case where two strings have different sizes, compare the sizes
                cout << "The first string is longer." << endl;
            else
                cout << "The second string is longer." << endl;
        }
    }
    ```
  - Input/Output:
    - ```c++
      //Input:
      abc abc
      //Output:
      The given strings are the same length.
      ``` 
    - ```c++
      //Input:
      abc ab
      //Output:
      The first string is longer.
      ``` 
    - ```c++
      //Input:
      abd abcd
      //Output:
      The second string is longer.
      ``` 
    - ```c++
      //Input: (two empty strings)
      
      //Output:
      The given strings are the same length.
      ```

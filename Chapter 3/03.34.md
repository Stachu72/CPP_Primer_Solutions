# Exercise 3.34
> Given that p1 and p2 point to elements in the same array, what does the following code do? Are there values of p1 or p2 that make this code illegal?

- ```c++
  p1 += p2 - p1;
  ```

## Solution

The expression `p1 += p2 - p1;` is a shorthand for `p1 = p1 - p1 + p2`, which can be simplified to `p1 = p2`. This means that `p1` now points to the value of `p2`. We can dereference the value pointed to by `p1` only if it is not an off-the-end pointer.

- **Code:**
    ```c++
    #include <iostream>
    using std::cout; using std::endl;
    int main() {
        int arr1[5] = { 0, 1, 2, 3, 4 }, *p1 = arr1, *p2 = arr1+1; //p1 points to the first element of array; p2 to the second
        cout << "The value of p1: " << *p1 << endl;
        cout << "The value of p2: " << *p2 << endl;
        p1 += p2 - p1; //p1 = p2
        cout << "The value of p1 after the assignment: " << *p1 << endl;
        cout << "The value of p2 after the assignment: " << *p2 << endl;
        return 0;
    }
    ```
  - Input/Output:
    ```c++
    The value of p1: 0
    The value of p2: 1
    The value of p1 after the assignment: 1
    The value of p2 after the assignment: 1
    ```

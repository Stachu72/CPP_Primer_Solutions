# Exercise 3.27
> Assuming txt_size is a function that takes no arguments and returns an int value, which of the following definitions are illegal? Explain why.

- `unsigned buf_size = 1024;` <br>
  - `int ia[buf_size];` <br>
  - `int ia[4 * 7 - 14];` <br>
  - `int ia[txt_size()];` <br>
  - `char st[11] = "fundamental";`

## Solution

_The dimension specifies the number of elements and must be greater than zero. [...] the dimension must be a constant expression._

- `int ia[buf_size];` - `buf_size` is not a constant expression, which means the dimension is not known at compile time. **Invalid**.
- `int ia[4 * 7 - 14];` - Basic mathematical operations on `int` literals results in a constant expression.**Valid**.
- `int ia[txt_size()];` - if `txt_size()` is a constant expression function - **valid**, otherwise **invalid**.
- `char st[11] = "fundamental";` - The word `fundamental` does indeed consist of 11 elements, but the character array must contain one more additional storage space for the `null terminator`, which means `st` must have at least `12` elements. **Invalid**.

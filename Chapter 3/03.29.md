# Exercise 3.29
> List some of the drawbacks of using an array instead of a vector.

## Solution

- **Modularity** - Dimensions of built-in array cannot be changed after it is defined; no elements can be added to it at runtime.
- **Dimension is a part of the array's type** - Unlike a vector, an array's dimension must be constant expression. <br>
- **No iterators** - An array does not support iterators, and must be accessed using subscript **[ ]operators**, or pointers. <br>
- **Cannot be copied** - It is an error to copy the contents of one array into another.

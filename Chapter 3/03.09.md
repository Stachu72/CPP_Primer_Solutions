# Exercise 3.9
> What does the following program do? Is it valid? If not, why not?

```c++
string s;
cout << s[0] << endl;
```

## Solution

The following program prints the first character of the string variable `s`. The problem is that the first element of this collection does not exist. The variable is default initialized (**string is empty**) just before it is used. The result of this operation is **undefined**.

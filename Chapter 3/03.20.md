# Exercise 3.20
> Read a set of integers into a vector. Print the sum of each pair of adjacent elements. Change your program so that it prints the sum of the first and last elements, followed by the sum of the second and second-to-last, and so on.

## Solution

- _Read a set of integers into a vector. Print the sum of each pair of adjacent elements._:

```c++
#include <iostream>
#include <vector>
using std::cin; using std::cout; using std::cerr; using std::endl; using std::vector;

int main() {
    vector<int> ivec;
    int userInput;
    cout << "Enter some integer numbers: "
    while (cin >> userInput)
        ivec.push_back(userInput);
    if (ivec.empty()) {
        cerr << "No input?!" << endl;
        return -1;
    }
    for (decltype(ivec.size()) i = 0; i < ivec.size()-1; i++) {
        cout << "The sum of elements: " << i << " and " << i+1 << " is: " << ivec[i] + ivec[i+1] << endl;
    }
    return 0;
}
```

- **Input/Output:**

```c++
Input:
1 2 3 4 5 6

Output:
The sum of elements: 0 and 1 is: 3
The sum of elements: 1 and 2 is: 5
The sum of elements: 2 and 3 is: 7
The sum of elements: 3 and 4 is: 9
The sum of elements: 4 and 5 is: 11
```

- _[...] prints the sum of the first and last elements, followed by the sum of the second and second-to-last, and so on._:

```c++
#include <iostream>
#include <vector>
using std::cin; using std::cout; using std::cerr; using std::endl; using std::vector;

int main() {
    vector<int> ivec;
    int userInput;
    cout << "Enter some integer numbers (do it in pairs): ";
    while (cin >> userInput)
        ivec.push_back(userInput);
    if (ivec.empty()) {
        cerr << "No input?!" << endl;
        return -1;
    }
    for (decltype(ivec.size()) i = 0; i < ivec.size()/2; i++) { //Note: The number of repetitions is equal to the size of ivec divided by 2 (we do not want to count the same elements twice e.g. 0 and 3 | 3 and 0)
        cout << "The sum of elements: " << i << " and " << ivec.size()-i-1 << " is: " << ivec[i] + ivec[ivec.size()-i-1] << endl;
    }
    return 0;
}
```

- **Input/Output**:

```c++
Input: 
10 20 30 100 50 2

Output:
The sum of elements: 0 and 5 is: 12
The sum of elements: 1 and 4 is: 70
The sum of elements: 2 and 3 is: 130
```

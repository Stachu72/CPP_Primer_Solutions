# Exercise 3.28
> What are the values in the following arrays?

```c++
string sa[10];
int ia[10];
int main() {
    string sa2[10];
    int ia2[10];
}
```

## Solution

```c++
string sa[10];      //Ten empty strings
int ia[10];         //Ten deafult-initialized ints | global scope = zeroed values
int main() {
    string sa2[10]; //Ten empty strings
    int ia2[10];    //Ten deafult-initialized ints | functions scope = undefined values
}
```

# Exercise 3.37
> What does the following program do?

- ```c++
  const char ca[] = {'h', 'e', 'l', 'l', 'o'};
  const char *cp = ca;
  while (*cp) {
      cout << *cp << endl;
      ++cp;
  }
  ```

## Solution

The following loop is printing the contents of the array, but it does not include a `null terminator`. This code may cause unwanted characters to appear after the array's contents are printed.

- Input/Output:
  - ```c++
    //Output:
    h
    e
    l
    l
    o
    8
    Ř
    č
    ä
    k
    ```
  - ```c++
    //Output:
    h
    e
    l
    l
    o
    h
    ű
    ┐
    h
    u
    ```

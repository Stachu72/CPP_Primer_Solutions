# Exercise 3.39
> Write a program to compare two strings. Now write a program to compare the values of two C-style character strings.

## Solution

- _Write a program to compare two strings._:
    ```c++
    #include <iostream>
    #include <string>
    using std::cout;
    using std::string;
    int main() {
        string str1 = "Hello ", str2 = "World!";
        if (str1 == str2) //checks whether the strings are equal
            cout << "The given strings are equal.";
        else
            if (str1 > str2) //checks which string is larger
                cout << "The first string is larger then the second.";
            else
                cout << "The second string is larger then the first.";
        return 0;
    }
    ```
  - Input/Output:
    - ```c++
      //Output: (for str1 = "Hello " and str2 = "World!")
      The second string is larger then the first.
      ```
    - ```c++
      //Output: (for str1 = "Hello " and str2 = "Hello")
      The first string is larger then the second.
      ```
    - ```c++
      //Output: (for str1 = "Hello World!" and str2 = "Hello World!")
      The given strings are equal.
      ```
      
- _Now write a program to compare the values of two C-style character strings._:
    ```c++
    #include <iostream>
    #include <cstring>
    using std::cout;
    int main() {
        const char ca1[] = "Hello ", ca2[] = "World!";
        if (strcmp(ca1, ca2) == 0) //checks whether character strings are equal
            cout << "The given character strings are equal.";
        else
            if (strcmp(ca1, ca2) > 0) //checks which character string is larger
                cout << "The first character string is larger than the second.";
            else
                cout << "The second character string is larger than the first.";
        return 0;
    }
    ```
  - Input/Output:
    - ```c++
      //Output: (for ca1 = "Hello " and ca2 = "World!")
      The second character string is larger than the first.
      ```
    - ```c++
      //Output: (for ca1 = "Hello " and ca2 = "Hello")
      The first character string is larger than the second.
      ```
    - ```c++
      //Output: (for ca1 = "Hello World!" and ca2 = "Hello World!")
      The given character strings are equal.
      ```

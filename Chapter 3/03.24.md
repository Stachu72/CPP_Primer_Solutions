# Exercise 3.24
> Redo the last exercise from § 3.3.3 [(3.20)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%203/03.20.md) using iterators.

## Solution

- _Read a set of integers into a vector. Print the sum of each pair of adjacent elements._:
    ```c++
    #include <iostream>
    #include <vector>
    using std::cin; using std::cout; using std::cerr; using std::endl;
    using std::vector;
    int main() {
        vector<int> ivec;
        int userInput;
        cout << "Enter some integer numbers: " << endl;
        while (cin >> userInput)
            ivec.push_back(userInput); //get integral numbers from the user input and store them in the vector
        if (ivec.empty()) { //the vector should not be empty
            cerr << "No input?!" << endl;
            return -1;
        }
        int index = 0;
        for (auto i = ivec.begin(); i < ivec.end()-1; ++i)
            cout << "The sum of elements: " << index << " and " << ++index << " is: " << *i + *(i+1) << endl; //print the indices of adjacent elements and their sum
        return 0;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    2 3 4 5 6 10 20 30
    //Output:
    The sum of elements: 0 and 1 is: 5
    The sum of elements: 1 and 2 is: 7
    The sum of elements: 2 and 3 is: 9
    The sum of elements: 3 and 4 is: 11
    The sum of elements: 4 and 5 is: 16
    The sum of elements: 5 and 6 is: 30
    The sum of elements: 6 and 7 is: 50
    ```

- _[...] prints the sum of the first and last elements, followed by the sum of the second and second-to-last, and so on._:
    ```c++
    #include <iostream>
    #include <vector>
    using std::cin; using std::cout; using std::cerr; using std::endl; 
    using std::vector;
    int main() {
        vector<int> ivec;
        int userInput;
        cout << "Enter some integer numbers (in pairs): " << endl;
        while (cin >> userInput)
            ivec.push_back(userInput); //get integral numbers from the user input and store them in the vector
        if (ivec.empty()) { //the vector should not be empty
            cerr << "No input?!" << endl;
            return -1;
        }
        int index = 0;
        for (auto i = ivec.begin(); i < ivec.begin() + ivec.size() / 2; ++i)  //Note: The number of repetitions is equal to the size of ivec divided by 2 (we do not want to count the same elements twice e.g. 0 and 3 | 3 and 0)
            cout << "The sum of elements: " << index << " and " << ++index << " is: " << *i + *(ivec.end()-index) << endl; //print the indices and the sum of the last and the first elements, followed by the indices and the sum of the second and the second-to-last elements, and so on.
        return 0;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    1 20 5 10 87 27
    //Output:
    The sum of elements: 0 and 1 is: 28
    The sum of elements: 1 and 2 is: 107
    The sum of elements: 2 and 3 is: 15
    ```

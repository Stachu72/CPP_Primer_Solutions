# Exercise 3.6
> Use a range for to change all the characters in a string to X

## Solution

- **Code:**
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl;
    using std::string; using std::getline;
    int main() {
        cout << "Enter a sentence: ";
        string userInput;
        getline(cin, userInput); //get a line input from the user
        //replace every character in the string with the letter X
        for (auto &letter : userInput) 
            letter = 'X';
        cout << "Your sentence, which has been changed: " << userInput << endl;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    Hello, World!
    //Output:
    Your sentence, which has been changed: XXXXXXXXXXXXX
    ```

# Exercise 3.10
> Write a program that reads a string of characters including punctuation and writes what was read but with the punctuation removed.

## Solution

```c++
#include <iostream>
using std::cin; using std::cout; using std::cerr; using std::endl; using std::string; using std::getline;

int main()
{
    cout << "Enter a sentence: ";
    string userInput;
    if (getline(cin, userInput)) {
        cout << "Your sentence without punctation: ";
        for (auto &letter : userInput){
            if (!ispunct(letter)) {
                cout << letter;
            }
        }
    }
    else {
        cerr << "No input!" << endl;
        return -1;
    }
}
```

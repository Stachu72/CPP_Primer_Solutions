# Exercise 3.10
> Write a program that reads a string of characters including punctuation and writes what was read but with the punctuation removed.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    #include <string>
    #include <cctype>
    using std::cin; using std::cout; using std::cerr; using std::endl;
    using std::string; using std::getline;
    int main()
    {
        cout << "Enter a sentence: ";
        string userInput;
        if (getline(cin, userInput)) { //get a line input from the user
            cout << "Your sentence without the punctation: ";
            for (auto &letter : userInput) //iterate through the string
                if (!ispunct(letter)) //|
                    cout << letter;   //| print only non-punctation characters
        }
        else {
            cerr << "No input!" << endl; //print information about no input
            return -1;
        }
        return 0;
    }
    ```
  - Input/Output:
    - ```c++
      //Input:
      Hello, World!
      //Output:
      Your sentence without the punctation: Hello World
      ```
    - ```c++
      //Input: (empty input)
      
      //Output:
      No input!
      ```

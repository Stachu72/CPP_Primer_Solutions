# Exercise 3.22
> Revise the loop that printed the first paragraph in text to instead change the elements in text that correspond to the first paragraph to all uppercase. After you’ve updated text, print its contents.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    #include <string>
    #include <vector>
    using std::cin; using std::cout; using std::cerr; using std::endl;
    using std::string; using std::vector; using std::getline;
    /* The program capitalizes all the words in the first paragraph */
    int main() {
        vector<string> svec;
        string userInput;
        while (getline(cin, userInput))
            svec.push_back(userInput); //get the line inputs by the user and store them in the vector
        if (svec.empty()) { //vector should not be empty
            cerr << "No input?!" << endl;
            return -1;
        }
        //capitalize all the words in the first paragraph
        for (auto it = svec.begin(); it != svec.end() && !it->empty(); ++it) { //repear the loop until the end of the vector, or until the first blank line (paragraph break | empty string)
            for (auto &c : *it)
                c = toupper(c);
        }
        //print each word in the vector
        for (const auto str : svec)
            cout << str << endl;
        return 0;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    hello world
    hi world
                // <-- paragraph break
    bye world
    //Output:
    HELLO WORLD
    HI WORLD
    
    bye world
    ```

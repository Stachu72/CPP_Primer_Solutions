# Exercise 3.5
> Write a program to read strings from the standard input, concatenating what is read into one large string. Print the concatenated string. Next, change the program to separate adjacent input strings by a space.

## Solution

- _Write a program to read strings from the standard input, concatenating what is read into one large string. Print the concatenated string._:
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl;
    using std::string;
    int main()
    {
        string input, sentence;
        while (cin >> input)  //keep getting the single word input by the user...
            sentence += input;  //...and adding it to the compound sentence
        cout << "Your sentence: " << sentence << endl;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    This    is a   single    word
    //Output:
    Your entence: Thisisasingleword
    ```

- _[...] change the program to separate adjacent input strings by a space_:
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl;
    using std::string;
    int main()
    {
        string input, sentence;
        while (cin >> input)          //keep getting the single word input by the user...
            sentence += input + " ";  //...and adding it to the compound sentence with the spaces
        cout << "Your sentence: " << sentence << endl;
    }
    ```
    - Input/Output:
       ```c++
      //Input:
      This is         a sentence
      //Output:
      Your sentence: This is a sentence
      ```

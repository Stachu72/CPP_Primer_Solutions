# Exercise 3.12
> Which, if any, of the following vector definitions are in error? For those that are legal, explain what the definition does. For those that are not legal, explain why they are illegal.

(a) `vector<vector<int>> ivec;` <br>
(b) `vector<string> svec = ivec;`  <br>
(c) `vector<string> svec(10, "null");`

## Solution

(a) `vector<vector<int>> ivec;` - This is a vector containing integers nested within another vector, <br>
(b) `vector<string> svec = ivec;` - Illegal initialization, vectors must be of the same type; in this case, an attempt is  made to copy a vector containing integers to a vector with containing strings, <br>
(c) `vector<string> svec(10, "null");` - Correct, the vector `svec`  now holds 10 strings named `null`.

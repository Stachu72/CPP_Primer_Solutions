# Exercise 3.41
> Write a program to initialize a vector from an array of ints.

## Solution

- **Code:**
  ```c++
  #include <cstddef>
  #include <iostream>
  #include <vector>
  using std::cout; using std::endl;
  using std::vector;
  int main() {
      const vector<int> ivec = { 0, 1, 2, 3, 4 };
      int arr[5];
      cout << "The elements of array: " << endl;
      for (size_t i = 0; i < ivec.size(); ++i) {
          arr[i] = ivec[i];      //copies the element from ivec to arr
          cout << arr[i] << " "; //prints the element of arr
      }
      return 0;
  }
  ```
  
  - Input/Output:
    ```c++
    //Output:
    The elements of array: 
    0 1 2 3 4
    ```

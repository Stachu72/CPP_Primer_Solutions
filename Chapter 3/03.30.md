# Exercise 3.30
> Identify the indexing errors in the following code:

```c++
constexpr size_t array_size = 10;
int ia[array_size];
for (size_t ix = 1; ix <= array_size; ++ix)
ia[ix] = ix;
```

## Solution

The loop ranges from 1 to 10, while the array has indices from 0 to 9. this causes a buffer overlow in the statement `ia[ix] = ix;` in the last iteration.

# Exercise 3.8
> Rewrite the program in the first exercise [(3.6)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%203/03.06.md), first using a while and again using a traditional for loop. Which of the three approaches do you prefer and why?

## Solution

- **While loop**:

```c++
#include <iostream>
using std::cin; using std::cout; using std::endl; using std::string; using std::getline;

int main()
{
    cout << "Enter a sentence: ";
    string userInput;
    getline(cin, userInput);
    decltype(userInput.size()) i = 0;
    while (i < userInput.size()) {
        userInput[i] = 'X';
        i++;
    }
    cout << "Your sentence in which every character has been replaced by an X: " << userInput << endl;
}
```

- **Traditional for loop**:

```c++
#include <iostream>
using std::cin; using std::cout; using std::endl; using std::string; using std::getline;

int main()
{
    cout << "Enter a sentence: ";
    string userInput;
    getline(cin, userInput);
    for (decltype(userInput.size()) i = 0; i < userInput.size(); i++){
        userInput[i] = 'X';
    }
    cout << "Your sentence in which every character has been replaced by an X: " << userInput << endl;
}
```

We can all agree that the best approach to this type of the exercise (working with collections) is a **range-based for loop**. Even the IDE suggests this option: `Clang-Tidy: Use range-based for loop instead`. The code looks clearer and more compact. There is no `decltype` syntax that would intoduce unnecessary complexity and force users to think more carefully about the code.

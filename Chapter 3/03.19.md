# Exercise 3.19
> List three ways to define a vector and give it ten elements, each with the value 42. Indicate whether there is a preferred way to do so and why.

## Solution

```c++
vector<int> v1(10, 42); //the simplest way to initialize a vector with the same elements
vector<int> v2{42, 42, 42, 42, 42, 42, 42, 42, 42, 42}; //the simplest way to initialize with a small number of different values
vector<int> v3; 
for (int i = 0; i < 10; i++) //the only way to add a specific value to a vector at runtime
    v3.push_back(42);
```

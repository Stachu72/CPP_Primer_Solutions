# Exercise 3.40
> Write a program to define two character arrays initialized from string literals. Now define a third character array to hold the concatenation of the two arrays. Use strcpy and strcat to copy the two arrays into the third.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  #include <cstring>
  using std::cout;
  int main() {
      char ca1[] = "Hello ", ca2[] = "World!", ca3[13]; //ca3[13] - 12 bytes for "Hello World!", and 1 byte for '\0' character
      strcpy(ca3, ca1); //copies ca1 to ca3
      strcat(ca3, ca2); //appends ca2 to ca3. ca3 now contains "Hello World\0"
      cout << ca3;
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Output:
    Hello World!
    ```

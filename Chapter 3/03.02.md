# Exercise 3.2
> Write a program to read the standard input a line at a time. Modify your program to read a word at a time.

## Solution

- _Write a program to read the standard input a line at a time.:_
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl; 
    using std::string; using std::getline;
    int main() {
        cout << "Enter a single-line input: ";
        string input;
        getline(cin, input); //getline function reads the entire line right to the end of the line
        cout << "Your input: " << input << endl;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    This is a single-line input
    //Output:
    Your input: This is a single-line input
    ```

- _Modify your program to read a word at a time.:_
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout; using std::endl; 
    using std::string;
    int main() {
        cout << "Enter single-word input: ";
        string input;
        cin >> input; //cin reads the first non-whitespace character up to the next space character it encounters
        cout << "Your input: " << input << endl;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    This is a single-word input
    //Output:
    Your input: This
    ```

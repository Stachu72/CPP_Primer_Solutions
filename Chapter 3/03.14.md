# Exercise 3.14
> Write a program to read a sequence of ints from cin and store those values in a vector.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    #include <vector>
    using std::cin; using std::cout; using std::endl;
    using std::vector;
    int main()
    {
        vector<int> collection;
        int userNumber;
        cout << "Enter some integer numbers: " << endl;
        while (cin >> userNumber) //get integer numbers from the user
            collection.push_back(userNumber); //add the numbers to the collection
        cout << "Your collection: ";
        //print the collection
        for (const auto i : collection)
            cout << i << " ";
        return 0;
    }
    ``` 
  - Input/Output:
    ```c++
    //Input:
    453 2345 7564 345 8765 234  64 534
    //Output:
    Your collection: 453 2345 7564 345 8765 234 64 534 
    ```

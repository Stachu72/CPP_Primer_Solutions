# Exercise 3.11
> Is the following range for legal? If so, what is the type of c?

```c++
const string s = "Keep out!";
for (auto &c : s) { /* ... */ }
```

## Solution

`auto` defines the variable `c` as a top-level const character and this makes it a reference to a constant character. i.e. `const char &c : ..`. The code is correct.

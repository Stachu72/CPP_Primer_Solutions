# Exercise 3.15
> Repeat the previous program [(3.14)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%203/03.14.md) but read strings this time.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    #include <string>
    #include <vector>
    using std::cin; using std::cout; using std::endl;
    using std::string; using std::vector;
    int main()
    {
        vector<string> collection;
        string userString;
        cout << "Enter some integer numbers: " << endl;
        while (cin >> userString) //get strings from the user
            collection.push_back(userString); //add the strings to the collection
        cout << "Your collection: ";
        //print the collection
        for (const auto str : collection)
            cout << str << " ";
        return 0;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    Hello , World !
    //Output:
    Your collection: Hello , World ! 
    ```

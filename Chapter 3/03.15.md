# Exercise 3.15
> Repeat the previous program [(3.14)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%203/03.14.md) but read strings this time.

## Solution

```c++
#include <iostream>
#include <vector>
using std::cin; using std::cout; using std::string; using std::vector;

int main()
{
    vector<string> collection;
    string userWord;
    cout << "Enter some words: ";
    while (cin >> userWord)
        collection.push_back(userWord);
    return 0;
}
```

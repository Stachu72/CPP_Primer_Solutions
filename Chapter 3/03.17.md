# Exercise 3.17
> Read a sequence of words from cin and store the values a vector. After you’ve read all the words, process the vector and change each word to uppercase. Print the transformed elements, eight words to a line.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    #include <string>
    #include <vector>
    #include <cctype>
    using std::cin; using std::cout; using std::cerr; using std::endl;
    using std::string; using std::vector;
    int main() {
        vector<string> sentence;
        string userInput;
        cout << "Enter some word inputs: " << endl;
        //get a word inputs by the user and add it to the vector
        while (cin >> userInput)
            sentence.push_back(userInput);
        if (sentence.empty()) { //the vector should not be empty
            cerr << "No input?!" << endl;
            return -1;
        }
        for (auto &word : sentence)  //for each string...
            for (auto &letter : word) //...and each character...
                letter = toupper(letter);   //...replace the lowercase letter with its corresponding uppercase letter
        int counter = 0; //Note: the counter keeps track of how many words have already been printed
        for (const auto word: sentence) {
            if (counter++ < 8)       
                cout << word << " "; //print a word from the vector
            else { //after printing 8 words
                cout << endl << word << " "; //print a word preceded by a new line
                counter = 1; //reset the counter
            }
        }
        return 0;
    }
    ```

# Exercise 3.17
> Read a sequence of words from cin and store the values a vector. After you’ve read all the words, process the vector and change each word to uppercase. Print the transformed elements, eight words to a line.

## Solution

- **Code:**

```c++
#include <iostream>
#include <vector>
using std::cin; using std::cout; using std::cerr; using std::endl; using std::string; using std::vector;

int main()
{
    vector<string> sentence;
    string userInput;
    while (cin >> userInput)
        sentence.push_back(userInput);      
    if (sentence.empty()) { //check whether the vector is empty
        cerr << "No input?!" << endl;
        return -1;
    }
    for (auto &word : sentence)
        for (auto &letter : word)
            letter = toupper(letter);       
    int counter = 0; //Note: the counter counts already printed words
    for (const auto word: sentence) {
        if (counter++ < 8)                  //if the counter value is less than 8..
            cout << word << " ";            //..print a word from the vector
        else {
            cout << endl << word << " ";    //after printing 8 words, first print a newline, and then the word
            counter = 1;                    //reset the counter
        }
    }
    return 0;
}
```

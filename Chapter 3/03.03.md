# Exercise 3.3
> Explain how whitespace characters are handled in the string input operator and in the getline function.

## Solution

- The string input operator ignores all whitespace characters, as long as it reads first non-whitespace character. It then reads all character until it encounter the next whitespace character.:
    ```c++
    //Input: 
        Hello World! 
    //How is it interpreted:
    Hello //Note: there is no spaces at the beginning of the line
    ```

- Getline function read all characters as they are, until a newline character.:
    ```c++
    //Input: 
         Hello World! 
    //How is it interpreted:
         Hello World! //Note: notice the 4 spaces at the beginning of the input
    ```

# Exercise 5.2
> What is a block? When might you use a block?

## Solution

A block (`{ }`) is used for grouping statements and may be placed whenever a single statement is expected:
```c++
while (condition)
    statement     //a while loop requires a single statement after the condition
another statement //this statement executes after the while loop

while (condition) {     //|
    statement           //|
    another statement   //|
}                       //|a block groups multiple statements into one statement
```

# Exercise 5.4
> Explain each of the following examples, and correct any problems you detect.

- ```c++
  while (string::iterator iter != s.end()) { /* . . . */ }
  ```
- ```c++
  while (bool status = find(word)) { /* . . . */ }
  if (!status) { /* . . . */ }
  ```

## Solution

- The first while loop tries to define the iterator `iter` and compare it at the same time, which leads to a syntax error. These operations have to be separated:
  ```c++
  string::iterator iter = s.begin();
  while (iter != s.end()) { /* . . . */ }
  ```
- The while loop scope variable `status` cannot be used outside the scope. Define the variable outside the scope:
  ```c++
  bool status;
  while (status = find(word)) { /* . . . */ }
  if (!status) { /* . . . */ }
  ```

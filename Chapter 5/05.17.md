# Exercise 5.17
> Given two vectors of ints, write a program to determine whether one vector is a prefix of the other. For vectors of unequal length, compare the number of elements of the smaller vector. For example, given the vectors containing 0, 1, 1, and 2 and 0, 1, 1, 2, 3, 5, 8, respectively your program should return true.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  #include <vector>
  using std::cout; using std::endl;
  using std::vector;
  int main() {
      vector<int> ivec1 = { 0, 1, 1, 2, 2, 3, 5, 8 }, ivec2 = { 0, 1, 1, 2 };
      const vector<int>::size_type size = ivec1.size() < ivec2.size() ? ivec1.size() : ivec2.size(); //get the size of the shorter vector
      for (vector<int>::size_type i = 0; i < size; ++i) {
          if (ivec1[i] != ivec2[i]) {
              cout << "Neither vectors is a prefix of the other." << endl;
              return 0;
          }
      }
      cout << "One vector is a prefix of the other." << endl;
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Output: (for ivec1 = { 0, 1, 1, 2, 2, 3, 5, 8 } and ivec2 = { 0, 1, 1, 2 })
    One vector is a prefix of the other.
    ```
    ```c++
    //Output: (for ivec1 = { 0, 2 } and ivec2 = { 0, 3, 2 })
    Neither vectors is a prefix of the other.
    ```

# Exercise 5.24
> Revise your program ([5.23]()) to throw an exception if the second number is zero. Test your program with a zero input to see what happens on your system if you don’t catch an exception.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  #include <stdexcept>
  using std::cin; using std::cout; using std::endl;
  int main() {
      int x, y;
      cout << "Enter two integers: ";
      cin >> x >> y;
      if (y != 0)
          cout << "The division of the entered integers is: " << x / y << endl;
      else
          throw std::runtime_error("Division by 0!");
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    10 2
    //Output:
    The division of the entered integers is: 5
    ```
    ```c++
    //Input:
    4 0
    //Output:
    terminate called after throwing an instance of 'std::runtime_error'
    what():  Division by 0!

    Process finished with exit code 3
    ```

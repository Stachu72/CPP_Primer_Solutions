# Exercise 5.22
> The last example in this section that jumped back to begin could be better written using a loop. Rewrite the code to eliminate the goto.

- **The last example:**
  ```c++
  //backward jump over an initialized variable definition is okay
  begin:
  int sz = get_size();
  if (sz <= 0) {
      goto begin;
  }
  ```

## Solution

- **Code:**
  ```c++
  int sz;
  do {
      sz = get_size();
  } while (sz <= 0);
  ```

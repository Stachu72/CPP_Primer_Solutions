# Exercise 5.6
> Rewrite your grading program ([5.5](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%205/05.05.md)) to use the conditional operator (§ 4.7, p. 151) in place of the if–else statement.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cin; using std::cout;
  int main() {
      unsigned int percentGrade;
      cout << "Enter the percentage of the exam result: ";
      if (cin >> percentGrade && percentGrade <= 100) { //process valid input
          char letterGrade;
          /*
           * less than 30      F
           * from 30 to 49     D
           * from 50 to 69     C
           * from 70 to 89     B
           * from 90 to 99     A
           * exactly 100       S
           */
          letterGrade = percentGrade < 30  ? 'F'
                      : percentGrade < 50  ? 'D'
                      : percentGrade < 70  ? 'C'
                      : percentGrade < 90  ? 'B'
                      : percentGrade < 100 ? 'A' : 'S';
          cout << "Your grade: " << letterGrade;
      }
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    28
    //Output:
    Your grade: F
    ```
    ```c++
    //Input:
    68
    //Output:
    Your grade: C
    ```
    ```c++
    //Input:
    99
    //Output:
    Your grade: A
    ```

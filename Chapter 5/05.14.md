# Exercise 5.14
> Write a program to read strings from standard input looking for duplicated words. The program should find places in the input where one word is followed immediately by itself. Keep track of the largest number of times a single repetition occurs and which word is repeated. Print the maximum number of duplicates, or else print a message saying that no word was repeated. For example, if the input is:
> 
> `how now now now brown cow cow` 
> 
> the output should indicate that the word now occurred three times.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  #include <string>
  using std::cin; using std::cout; using std::endl;
  using std::string;
  int main() {
      string currentWord, previousWord, bestWord; //these variables hold the currently and previously read words, and the most repeated word so far
      int wordCount = 1, maxWordCount = 1;        //these variables hold the current word count and the maximum count found so far
      while (cin >> currentWord) {
          if (currentWord == previousWord)
              ++wordCount;
          else
              wordCount = 1;
          if (maxWordCount < wordCount) {
              maxWordCount = wordCount;
              bestWord = currentWord;
          }
          previousWord = currentWord;
      }
      if (maxWordCount == 1)
          cout << "There are no repeated words." << endl;
      else
          cout << "The word " << bestWord << " occurred " << maxWordCount << " times." << endl;
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    how now now now brown cow cow
    //Output:
    The word now occurred 3 times.
    ```
    ```c++
    //Input:
    cow cow cow cow
    //Output:
    The word cow occurred 4 times.
    ```
    ```c++
    //Input:
    cow dog cat lion
    //Output:
    There are no repeated words.
    ```

# Exercise 5.5
> Using an if–else statement, write your own version of the program to generate the letter grade from a numeric grade.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cin; using std::cout; 
  int main() {
      unsigned int percentGrade;
      cout << "Enter the percentage of the exam result: ";
      if (cin >> percentGrade && percentGrade <= 100) { //process valid input
          char letterGrade;
          /*
           * less than 30      F
           * from 30 to 49     D
           * from 50 to 69     C
           * from 70 to 89     B
           * from 90 to 99     A
           * exactly 100       S
           */
          if (percentGrade < 30)
              letterGrade = 'F';
          else if (percentGrade < 50)
              letterGrade = 'D';
          else if (percentGrade < 70)
              letterGrade = 'C';
          else if (percentGrade < 90)
              letterGrade = 'B';
          else if (percentGrade < 100)
              letterGrade = 'A';
          else
              letterGrade = 'S';
          cout << "Your grade: " << letterGrade;
      }
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    28
    //Output:
    Your grade: F
    ```
    ```c++
    //Input:
    68
    //Output:
    Your grade: C
    ```
    ```c++
    //Input:
    99
    //Output:
    Your grade: A
    ```

# Exercise 5.15
> Explain each of the following loops. Correct any problems you detect.

- ```c++
  for (int ix = 0; ix != sz; ++ix) { /* ... */ }
  if (ix != sz)
      //...
  ```
- ```c++
  int ix;
  for (ix != sz; ++ix) { /* ... */ }
  ```
- ```c++
  for (int ix = 0; ix != sz; ++ix, ++ sz) { /* ... */ }
  ```

## Solution

- The loop `for (int ix = 0; ix != sz; ++ix)` defines the loop scope variable `ix` and the if statement tries to access it outside its scope. Define the variable outside the loop:
  ```c++
  int ix = 0;
  for ( ; ix != sz; ++ix) { /* . . . */ }
  if (ix != sz)
  //...
  ```
- The loop `for (ix != sz; ++ix)` contains the condition (`ix != sz`) in the initialization section. Rearrange the loop header:
  ```c++
  int ix = 0; //initialize ix
  for ( ; ix != sz; ++ix) { /* . . . */ } //added a semicolon after the (empty) definition
  ```
- The loop `for (int ix = 0; ix != sz; ++ix, ++ sz)` is very similar to the first one (`(int ix = 0; ix != sz; ++ix)`), but it contains one additional expression (`++ sz`), which increments `sz`. The loop is (potentially) endless, because the distance between `ix` and `sz` never changes.

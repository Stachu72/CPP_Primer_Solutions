# Exercise 5.21
> Revise the program from the exercise in § 5.5.1 ([5.20](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%205/05.20.md)) so that it looks only for duplicated words that start with an uppercase letter.

## Solution

- **Code:**
  ```c++
  #include <cctype>
  #include <iostream>
  #include <string>
  using std::cin; using std::cout; using std::endl;
  using std::string;
  int main() {
      string str, previousStr;
      bool isRepeated = false;
      while (cin >> str) {
          if (!isupper(str[0])) continue;
          if (!previousStr.empty() && str == previousStr) {
              cout << "The word " << str << " has been repeated." << endl;
              isRepeated = true;
              break;
          }
          previousStr = str;
      }
      if (!isRepeated)
          cout << "No word was repeated." << endl;
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    dog dog
    //Output:
    No word was repeated.
    ```
    ```c++
    //Input:
    Cat fish Cat
    //Output:
    The word Cat has been repeated.
    ```

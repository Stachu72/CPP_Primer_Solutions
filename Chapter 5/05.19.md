# Exercise 5.19
> Write a program that uses a do while loop to repetitively request two strings from the user and report which string is less than the other.

- **Code:**
  ```c++
  #include <iostream>
  #include <string>
  using std::cin; using std::cout; using std::endl;
  using std::string;
  int main() {
      do {
          string str1, str2;
          cout << "Enter two strings: \n";
          if (cin >> str1 >> str2) {
            if (str1 < str2)
                cout << "The first string is less than the second." << endl;
            else if (str1 > str2)
                cout << "The second string is less than the first." << endl;
            else
                cout << "The strings are equal." << endl;
          }
      } while (cin); //the loop executes until an invalid input is encountered
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    abc abb
    //Output:
    The second string is less than the first.
    ```
    ```c++
    //Input:
    abd abj
    //Output:
    The first string is less than the second.
    ```
    ```c++
    //Input:
    aa aa
    //Output:
    The strings are equal.
    ```

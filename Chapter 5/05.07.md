# Exercise 5.7
> Correct the errors in each of the following code fragments:

- ```c++ 
  if (ival1 != ival2)
    ival1 = ival2
  else ival1 = ival2 = 0;
  ```
- ```c++ 
  if (ival < minval)
    minval = ival;
    occurs = 1;
  ``` 
- ```c++ 
  if (int ival = get_value())
    cout << "ival = " << ival << endl;
  if (!ival)
    cout << "ival = 0\n";
  ``` 
- ```c++ 
  if (ival = 0)
    ival = get_value();
  ```

## Solution

- ```c++ 
  if (ival1 != ival2)
    ival1 = ival2; //there was no semicolon at the end of the line
  else ival1 = ival2 = 0;
  ```
- ```c++ 
  if (ival < minval) {
    minval = ival;
    occurs = 1; //this statement wasn't part of the if statement
  }
  ``` 
- ```c++ 
  int ival = get_value(); //initializes ival here
  if (ival)               
    cout << "ival = " << ival << endl;
  if (!ival) //the previous location of the declaration doesn't allow using ival in the second if statment
    cout << "ival = 0\n";
  ```
- ```c++ 
  if (ival == 0) //usaed assignment instead of comparision
    ival = get_value();
  ```

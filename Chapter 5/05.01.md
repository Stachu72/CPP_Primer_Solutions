# Exercise 5.1
> What is a null statement? When might you use a null statement?

## Solution

The null statement (`;`) is the standalone semicolon that is paired with no expression. 
- The null statement may be placed unwittingly right after another statement:
    ```c++
    int i = 0;; //the last semicolon is redundant
    ```
- The use of a null statement is sometimes helpful; it may help search for a specific value in a vector:
    ```c++
    for ( ; i < ivec.size() && ivec[i] != 10 ; i++) 
        ; //null statement
    ```
  In this scenario, the loop uses an empty body, because all necessary work is done in the loop header. The condition checks whether the index `i` is valid and the element at that index is not equal to `10`.

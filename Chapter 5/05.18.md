# Exercise 5.18
> Explain each of the following loops. Correct any problems you detect.

- ```c++
  do
      int v1, v2;
      cout << "Please enter two numbers to sum:" ;
      if (cin >> v1 >> v2)
          cout << "Sum is: " << v1 + v2 << endl;
  while (cin);
  ```
- ```c++
  do {
      // . . .
  } while (int ival = get_response());
  ```
- ```c++
  do {
      int ival = get_response();
  } while (ival);
  ```


## Solution

- The loop sums two integer values passed by the user, and then prints them. Unfortunately, the loop statement is invalid, due to the lack of a loop body (`{ }`). Add braces to fix the issue:
  ```c++
  do { //the start of the body
      int v1, v2;
      cout << "Please enter two numbers to sum:" ;
      if (cin >> v1 >> v2)
          cout << "Sum is: " << v1 + v2 << endl;
  } //the end of the body
  while (cin); 
  ```
- The do-while loop does not allow variable definitions inside the condition. Move the definition outside the loop:
  ```c++
  int ival; //the definition is moved from the condition
  do {
      // . . .
  } while (ival = get_response());
  ```
- Variables used in the condition must be defined outside the body of the do-while statement. Move the definition outside the loop body:
  ```c++
  int ival; //the definition is moved from the loop body
  do {
      ival = get_response();
  } while (ival);
  ```

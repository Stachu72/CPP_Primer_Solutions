# Exercise 5.23
> Write a program that reads two integers from the standard input and prints the result of dividing the first number by the second.

## Solution

- **Code:**
  ```c++
  #include <iostream>
  using std::cin; using std::cout; using std::endl;
  int main() {
      int x, y;
      cout << "Enter two integers: ";
      cin >> x >> y;
      cout << "The division of the entered integers is: " << x / y << endl;
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    10 2
    //Output:
    The division of the entered integers is: 5
    ```
    ```c++
    //Input:
    4 0
    //Output:
    Error
    ```

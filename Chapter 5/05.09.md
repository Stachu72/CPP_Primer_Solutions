# Exercise 5.9
> Write a program using a series of if statements to count the number of vowels in text read from cin.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    #include <string>
    using std::cin; using std::cout;
    using std::string;
    int main() {
        string userInput;
        if (cin >> userInput) { //get valid user input
            int vowelCnt = 0;
            //for each vowel, increment the vowel count
            for (char c : userInput) {
                if (c == 'a') ++vowelCnt;
                else if (c == 'e') ++vowelCnt;
                else if (c == 'i') ++vowelCnt;
                else if (c == 'o') ++vowelCnt;
                else if (c == 'u') ++vowelCnt;
            }
            cout << "The number of vowels: " << vowelCnt; //print the vowel count
        }
        return 0;
    }
    ```
  - Input/Output:
    ```c++
    //Input:
    Hello, World!
    //Output:
    The number of vowels: 2
    ```

# Exercise 5.25
> Revise your program from the previous exercise ([5.24](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%205/05.24.md)) to use a try block to catch the exception. The catch clause should print a message to the user and ask them to supply a new number and repeat the code inside the try.

## Solution

- **Code:**
  ```c++
  #include <stdexcept>
  #include <iostream>
  using std::cin; using std::cout; using std::endl;
  using std::runtime_error;
  int main() {
      int x, y;
      cout << "Enter two integers: ";
      while (cin >> x >> y) {
          try {
              if (y != 0) {
                  cout << "The division of the entered integers is: " << x / y << endl;
                  break;
              }
              else
                  throw runtime_error("Division by 0!");
          }
          catch (runtime_error err) {
              cout << err.what() << endl;
              cout << "Please enter two correct integers: ";
          }
      }
      return 0;
  }
  ```
  - Input/Output:
    ```c++
    //Input:
    4 2
    //Output:
    The division of the entered integers is: 2
    ```
    ```c++
    //Input:
    4 0
    //Output:
    Division by 0!
    Please enter two correct integers:
    //Input:
    10 1
    //Output:
    The division of the entered integers is: 10
    ```

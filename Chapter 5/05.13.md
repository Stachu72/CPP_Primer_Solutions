# Exercise 5.13
> Each of the programs in the highlighted text on page 184 contains a common programming error. Identify and correct each error.

- ```c++
  unsigned aCnt = 0, eCnt = 0, iouCnt = 0;
  char ch = next_text();
  switch (ch) {
      case 'a': aCnt++;
      case 'e': eCnt++;
      default: iouCnt++;
  }
  ```
- ```c++
  unsigned index = some_value();
  switch (index) {
      case 1:
          int ix = get_value();
          ivec[ ix ] = index;
          break;
      default:
          ix = ivec.size()-1;
          ivec[ ix ] = index;
  }
  ```
- ```c++
  unsigned evenCnt = 0, oddCnt = 0;
  int digit = get_num() % 10;
  switch (digit) {
      case 1, 3, 5, 7, 9:
          oddcnt++;
          break;
      case 2, 4, 6, 8, 0:
          evenCnt++;
          break;
  }
  ```
- ```c++
  unsigned ival=512, jval=1024, kval=4096;
  unsigned bufsize;
  unsigned swt = get_bufCnt();
  switch(swt) {
      case ival:
          bufsize = ival * sizeof(int);
          break;
      case jval:
          bufsize = jval * sizeof(int);
          break;
      case kval:
          bufsize = kval * sizeof(int);
          break;
  }
  ```

## Solution

- There is no `break` in the switch statement. Each case will execute sequentially due to fallthrough: 
  ```c++
  unsigned aCnt = 0, eCnt = 0, iouCnt = 0;
  char ch = next_text();
  switch (ch) {
      case 'a': 
          aCnt++;
          break; //added break statement
      case 'e': 
          eCnt++;
          break; //added break statement
      default: 
          iouCnt++;
          break; //added break statement
  }
  ```
- Initializing the variable in a case statement is legal, but defining it outside a block (`{}`) and then accessing it in another case causes an error:
  ```c++
  unsigned index = some_value();
  int ix = get_value(); //moved the definiton outside the case 1 
  switch (index) {
      case 1:
          ivec[ ix ] = index;
          break;
      default:
          ix = ivec.size()-1;
          ivec[ ix ] = index;
  }
  ```
- A case label has to contain only a single integral constant expression value:
  ```c++
  unsigned evenCnt = 0, oddCnt = 0;
  int digit = get_num() % 10;
  switch (digit) {
      case 1: case 3: case 5: case 7: case 9: //each case label has only a one constant expression
          oddCnt++;
          break;
      case 2: case 4: case 6: case 8: case 0: //each case label has only a one constant expression
          evenCnt++;
          break;
  }
  ```
- A case label has to be a constant expression value:
  ```c++
  constexpr unsigned ival=512, jval=1024, kval=4096; //the variables are a constant expression
  unsigned bufsize;
  unsigned swt = get_bufCnt();
  switch(swt) {
      case ival: //ival is a constant expr
          bufsize = ival * sizeof(int);
          break;
      case jval: //jval is a constant expr
          bufsize = jval * sizeof(int);
          break;
      case kval: //kval is a constant expr
          bufsize = kval * sizeof(int);
          break;
  }
  ```

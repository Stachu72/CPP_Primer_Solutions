# Exercise 5.8
> What is a “dangling else”? How are else clauses resolved in C++?

## Solution

The term `dangling else` refers to a situation where the number of else statements is lower than the number of if statements. This creates an ambiguity as to which if statement a given else belongs to. An else statement belongs to the nearest preceding unmatched if statement:
```c++
if (condition1)    
    if (condition2) 
        statement2 
else //this else belongs to the second if statement
    statement2
```
To prevent such potential errors, use curly braces (`{}`) to create a block:
```c++
if (condition1) {
    if (condition2)
        statement2 
}
else //this else belongs to the first if statement
    statement1
```

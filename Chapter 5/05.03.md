# Exercise 5.3
> Use the comma operator (§ 4.10, p. 157) to rewrite the while loop from § 1.4.1 (p. 11) so that it no longer requires a block. Explain whether this rewrite improves or diminishes the readability of this code.

- **While loop from p. 11:**
    ```c++
    while (val <= 10) {
        sum += val;
        ++val;
    }
    ```

## Solution

- **Code with a single line statement:**
    ```c++
    while (val <= 10)
        sum += val, ++val;
    ```
This code is completely legal but might be misleading. Instead, use a block (`{ }`) or combine two statements into one (if possible): 
```c++
while (val <= 10) {
    sum += val; ++val; //using semicolons makes it easier to understand that these are two separate statements
} 
//or
while (val <= 10) 
    sum += val++; //combination of two separate statements into a single one
```

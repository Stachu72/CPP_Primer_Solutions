# Exercise 1.3
>  Write a program to print Hello, World on the standard output.

## Solution

- **Code:**
    ```c++
    #include <iostream>
    
    int main() {
        std::cout << "Hello World!" << std::endl;
        return 0;
    }
    ```

- **Input/Output:**
    ```c++
    /** Output: **/
    Hello World!
    ```

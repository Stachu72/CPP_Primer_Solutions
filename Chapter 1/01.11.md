# Exercise 1.11
>  Write a program that prompts the user for two integers. Print each number in the range specified by those two integers.

## Solution

```c++
#include <iostream>
int main()
{
    int numberA = 0, numberB = 0;
    std::cout << "Enter two numbers (the smaller one first), separated by a space: ";
    std::cin >> numberA >> numberB;
    while (numberA < numberB-1) {
        numberA++;
        std::cout << numberA << std::endl;
    }
    return 0;
}
```

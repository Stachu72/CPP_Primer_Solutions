# Exercise 1.11
>  Write a program that prompts the user for two integers. Print each number in the range specified by those two integers.

## Solution

- **Code:**
  ```c++
  #include <iostream>

  int main() {
    int numA, numB;
    std::cout << "Enter two numbers (the smaller one first), separated by a space: " << std::endl; 
    std::cin >> numA >> numB; //prompt the user for two integral numbers
    while (numA < numB-1) {         // |
        numA++;                     // | ---> in a loop, add 1 to numA and print that value until it reaches a value equal numB reduced by 1
        std::cout << numA << " ";   // |
    }
    return 0;
  }
  ```

- **Input/Output:**
  ```c++
  /** Input: **/
  2 10
  
  /** Output: **/
  3 4 5 6 7 8 9
  ```

# Exercise 1.7
>  Compile a program that has incorrectly nested comments.

## Solution

- **Code:** 
    ```c++
    #include <iostream>
    
    int main() {
       /* /* */ */
       return 0;
    }
    ```

- **Input/Output:** 
    ```c++
    /** An error has occured: **/
    error: expected primary-expression before '/' token
    2 |     /* /* */ */
      |               ^
    ```

# Exercise 1.13
>  Rewrite the first two exercises from § 1.4.1, using for loops

- _Write a program that uses a while to sum the numbers from 50 to 100. [(1.9)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%201/01.09.md)_:
    ```c++
    #include <iostream>

    int main() {
        int num = 50, sum = 0;
        while (num <= 100) { // check whether the number is still within the range (is smaller than/equal to 100)
            sum += num;      // | (sum = sum + number;)
            num++;           // | in each iteration, add the number to the total sum and increase that number by 1
        }
        std::cout << "The sum of the numbers from 50 to 100 inclusive, is: " << sum << std::endl; //print the sum
        return 0;
    }
    ```
<br>

- _Use the decrement operator to write a while that prints the numbers from ten down to zero. [(1.10)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%201/01.10.md)_:
    ```c++
    #include <iostream>

    int main() {
        int num = 10; // the number from which we count down
        while (num >= 0) { //check whether the number is not a negative number
            std::cout << num << " "; // |
            num--;                   // | in each iteration, print the number and decrese it by 1
        }
    return 0;
    }
    ```

## Solution

- _Write a program that uses a while to sum the numbers from 50 to 100. [(1.9)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%201/01.09.md)_:
    ```c++
    int sum = 0;
    for (int num = 50; num <= 100; num++) { // |
        sum += num;                         // | add the number to the sum, then increase that number by 1, reapet this process as long as the number is less than 100
    }
    ```
<br>

- _Use the decrement operator to write a while that prints the numbers from ten down to zero. [(1.10)](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%201/01.10.md)_:
    ```c++
    for (int number = 10; number >= 0; number--)    // |
        std::cout << number << std::endl;           // | the loop is executed 10 times, decreasing the number by 1 each time and printing its value
    ```

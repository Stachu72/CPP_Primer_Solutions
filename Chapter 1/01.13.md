# Exercise 1.13
>  Rewrite the first two exercises from § 1.4.1 (p. 13) using for loops

<br/>

**The loops from p. 13:**
```cpp
int number = 50, sum = 0;
while (number <= 100) {
    sum += number;
    number++;
}
```

```cpp
int number = 10;
while (number >= 0) {
    std::cout << number << std::endl;
    number--;
}
```

## Solution

```cpp
int sum = 0;
for (int number = 50; number <= 100; number++) {
    sum += number;
}
```

```cpp
for (int number = 10; number >= 0; number--) 
    std::cout << number << std::endl;
```

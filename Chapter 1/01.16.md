# Exercise 1.16
>  Write your own version of a program that prints the sum of a set of integers read from cin.

## Solution

```c++
#include <iostream>
int main()
{
    int number = 0, sum = 0;
    std::cout << "Enter the numbers, separating them with a space: ";
    while (std::cin >> number)
        sum += number;
    std::cout << "The sum of those numbers is equal to: " << sum << std::endl;
    return 0;
}
```

# Exercise 1.6
>  Explain whether the following program fragment is legal. If the program is legal, what does it do? If the program is not legal, why not? How would you fix it?

- **Code:**
  ```c++
  #include <iostream>
  
  int main() {
      std::cout << "The sum of " << v1;
      << " and " << v2;
      << " is " << v1 + v2 << std::endl;
      return 0;
  }
  ```

## Solution

- *If the program is legal, what does it do? If the program is not legal, why not?* <br/>
  - The program is illegal because the left operand of the **<< operator** is missing. The `;` sign at the end of the line, right before the **<< operator**, causes the preceding part of the expression to be cut.
  

- *How would you fix it?*
  - There are two ways to solve this problem. One of them is remove the `;` signes before **<< operator**.
    ```c++
    #include <iostream>
    
    int main() {
        std::cout << "The sum of " << v1    // | 
        << " and " << v2                    // | Note: `;` signes were removed
        << " is " << v1 + v2 << std::endl;
        return 0;
    }
    ```
    
  - The second way is to add `std::cout` before the **<< operator** wherever it is needed.
    ```c++
    #include <iostream>
    
    int main() {
        std::cout << "The sum of " << v1;   
        std::cout << " and " << v2;                     // | 
        std::cout << " is " << v1 + v2 << std::endl;    // | Note: `std::cout` statements were added
        return 0;
    }
    ```

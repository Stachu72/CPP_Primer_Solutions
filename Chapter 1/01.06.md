# Exercise 1.6
>  Explain whether the following program fragment is legal. If the program is legal, what does it do? If the program is not legal, why not? How would you fix it?

<br/>

**Program:**
```cpp
#include <iostream>
int main()
{
    std::cout << "The sum of " << v1;
	<< " and " << v2;
	<< " is " << v1 + v2 << std::endl;
    return 0;
}
```

## Solution

*If the program is legal, what does it do? If the program is not legal, why not?* <br/>
  - The program is illegal because the left operand of the **<< operator** is missing. The `;` sign at the end of the line, right before the **<< operator**, causes the preceding part of the expression to be cut.<br/>


*How would you fix it?*
  - There are two ways to solve this problem. One of them is remove the `;` signes before **<< operator**. Why would this solve the problem? Because this operator returns its left-handed operand. In a nutshell, the operator will treat the left side as `std::cout`. 
  - The second way is to add `std::cout` before the **<< operator** wherever it is needed.

# Exercise 1.8
>  Indicate which, if any, of the following output statements are legal: (see below). After you’ve predicted what will happen, test your answers by compiling a program with each of these statements. Correct any errors you encounter. 

- **Code:**
    ```c++
    std::cout << "/*";
    std::cout << "*/";
    std::cout << /* "*/" */;
    std::cout << /* "*/" /* "/*" */;
    ```

After you’ve predicted what will happen, test your answers by compiling a program
with each of these statements. Correct any errors you encounter.

## Solution

- `std::cout << "/*";` - valid, the comment does not work in strings, 
- `std::cout << "*/";` - valid, the comment does not work in strings,
- `std::cout << /* "*/" */;` - the first block of the comment ends just before the second `"` sign. This causes an error due to the lack of a matching pair of these signs. Removing the phrase `"*/"`  will cause another problem - the **<< operator** is missing the right-hand operand. Either remove the entire expression, or remove the comment markers on both sides of the string,
- `std::cout << /* "*/" /* "/*" */;` - valid.

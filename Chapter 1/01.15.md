# Exercise 1.15
>  Write programs that contain the common errors discussed in the box on page 16. Familiarize yourself with the messages the compiler generates.

## Solution

- *Syntax error*
```c++
//error: missing ) in parameter list for main
int main ( {
    //error: used colon, not a semicolon, after endl
    std::cout << "Read each file." << std::endl:
    //error: missing quotes around string literal
    std::cout << Update master. << std::endl;
    //error: second output operator is missing
    std::cout << "Write new master." std::endl;
    //error: missing ; on return statement
    return 0
}
```
Output messages:
```
1 | //error: missing ) in parameter list for main

error: found ':' in nested-name-specifier, expected '::'
    5 |     std::cout << "Read each file." << std::endl:
      |                                                ^
      |                                                ::
  
error: expected '}' before 'master'
    7 |     std::cout << Update master. << std::endl;
      |                         ^~~~~~
note: to match this '{'
    3 | int main ( {
      |            ^
  
error: expected ')' before 'master'
    7 |     std::cout << Update master. << std::endl;
      |                        ^~~~~~~
      |                        )
note: to match this '('
    3 | int main ( {
      |          ^
      
and more...
```

- *Type errors*
```c++
int main () {
    //error: passing string literal to integer variable
    int number = "Hello World!";
    return 0;
}
```
Output message: 
```
error: invalid conversion from 'const char*' to 'int' [-fpermissive]
    2 |     int number = "Hello World!";
      |                  ^~~~~~~~~~~~~~
      |                  |
      |                  const char*
```

- *Declaration errors*
```c++
#include <iostream>
int main()
{
    int v1 = 0, v2 = 0;
    std::cin >> v >> v2; //error: uses "v" not "v1"
    //error: cout not defined; should be std::cout
    cout << v1 + v2 << std::endl;
    return 0;
}
```
Output message:
```
error: 'v' was not declared in this scope; did you mean 'v2'?
    5 |     std::cin >> v >> v2; //error: uses "v" not "v1"
      |                 ^
      |                 v2
      
error: 'cout' was not declared in this scope; did you mean 'std::cout'?
    7 |     cout << v1 + v2 << std::endl;
      |     ^~~~
      |     std::cout
```

**As you can see, sometime the IDE suggests more complicated solutions than they actually are.**

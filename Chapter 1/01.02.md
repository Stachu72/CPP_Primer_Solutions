# Exercise 1.2 
>  Change the program to return -1. A return value of -1 is often treated as an indicator that the program failed. Recompile and rerun your program to see how your system treats a failure indicator from main.

## Solution 

- **Code:**
    ```c++
    int main() { 
        return -1; 
    }
    ```
    
- **Input/Output:**
    ```c++
    //There is neither input nor output
    ```

- **Conclusion:** <br>
The program itself treats this change as insignificant. The program simply returns a value other from 0, which indicates that an error has occurred. This system is useful when one standalone program depends on another, if the first program returns a nonzero value, the second program will not run.

\# Exercise 1.2 

>  Change the program to return -1. A return value of -1 is often treated as an indicator that the program failed. Recompile and rerun your program to see how your system treats a failure indicator from main.



\## Solution 



\- Changed program:

```cpp

int main()

{ 

&#x09;return -1; 

}

```



\- Conclusion:

&#x09;\*\*The program itself treats this change as insignificant.\*\* However, it is helpful when running two different programs, especially if second one depends on the first. There are also others features that rely on returning a non zero `int`. E.g. we apply this logic with an external file; If the file fails to load, the program terminates and returns the error code.

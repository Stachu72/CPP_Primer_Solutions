# Exercise 1.5
>  We wrote the output in one large statement. Rewrite the program to use a separate statement to print each operand.

- **Code:**
    ```c++  
    #include <iostream>
    
    int main() {
        int v1, v2;
        std::cout << "Enter two integral numbers:" << std::endl;
        std::cin >> v1 >> v2; //prompt the user for two integral numbers
        std::cout << "The sum of " << v1 << " and " << v2 
        << " is " << v1 + v2 << std::endl; //print the sum of the user's numbers
        return 0;
    }
    ```

- **Input/Output:**
    ```c++
    /** Input: **/
    2 5
    
    /** Output: **/
    The sum of 2 and 5 is 7
    ```
    
## Solution
    
- **Code:**
    ```c++
    #include <iostream>
    
    int main() {
        std::cout << "Enter two numbers:" << std::endl;
        int v1 = 0, v2 = 0;
        std::cin >> v1 >> v2; //prompt the user for two integral numbers
        std::cout << "The sum of "; // |
        std::cout << v1;            // |
        std::cout << " and ";       // | ---> print the information about the summation, but not the result itself
        std::cout << v2;            // |        
        std::cout << " is ";        // |
        std::cout << v1 + v2;       // print the result of the sum of the user's numbers
        std::cout << std::endl;     // print a new line
        return 0;
    }
    ```
    
- **Input/Output:**
    ```c++
    /** Input: **/
    2 5
    
    /** Output: **/
    The sum of 2 and 5 is 7
    ```

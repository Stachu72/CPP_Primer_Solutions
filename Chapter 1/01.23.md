# Exercise 1.23
> Write a program that reads several transactions and counts how many transactions occur for each ISBN.

## Solution

```c++
#include "Sales_item.h"

int main() {
    Sales_item book, nextBook;
    int count = 1;
    std::cin >> book;  //get the first isbn off the first read book
    while (std::cin >> nextBook) {
        if (book.isbn() == nextBook.isbn()) //check if the isbn is the same as the referenced isbn
            count++;
        else {
            std::cout << "The " << book.isbn() << " isbn number has appeared " << count << " times." << std::endl;
            book = nextBook;
            count = 1;
        }
    }
    std::cout << book.isbn();
    std::cout << "The " << book.isbn() << " isbn number has appeared " << count << " times." << std::endl;
    return 0;
}
```

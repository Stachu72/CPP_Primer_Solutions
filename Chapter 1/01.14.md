# Exercise 1.14
>  Compare and contrast the loops that used a for with those using a while. Are there advantages or disadvantages to using either form?

## Solution

- As shown in the previous exercise ([1.13](https://github.com/Stachu72/CPP_Primer_Solutions/blob/main/Chapter%201/01.13.md)), using an integer variable and an expression in a `for` loop header is very handy and saves a few extra lines of code. Unfortunately it sometimes sometime happems that the value from the init-statement is needed after the completion of the loop, so it must be initialized the same way as in the `while` loop. 
- If you need a loop based on numbers use a `for` loop, and if you concentrate on different type of variables, use a `while` loop instead.

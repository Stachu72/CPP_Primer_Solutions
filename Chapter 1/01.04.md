# Exercise 1.4
>  Our program used the addition operator, +, to add two numbers. Write a program that uses the multiplication operator, *, to print the product instead.

- **Code:**
    ```c++  
    #include <iostream>
    
    int main() {
        int v1, v2;
        std::cout << "Enter two integral numbers:" << std::endl;
        std::cin >> v1 >> v2; //prompt the user for two integral numbers
        std::cout << "The sum of " << v1 << " and " << v2 
        << " is " << v1 + v2 << std::endl; //print the sum of the user's numbers
        return 0;
    }
    ```

- **Input/Output:**
    ```c++
    /** Input: **/
    2 5
    
    /** Output: **/
    The sum of 2 and 5 is 7
    ```

## Solution

- **Code:**
    ```c++
    #include <iostream>
    
    int main() {
        std::cout << "Enter two numbers:" << std::endl;
        int v1 = 0, v2 = 0;
        std::cin >> v1 >> v2; //prompt the user for two integral numbers
        std::cout << "The product of " << v1 << " and " << v2
        << " is " << v1 * v2 << std::endl; //print the product of the user's numbers
        return 0;
    }
    ```

- **Input/Output:**
    ```c++
    /** Input: **/
    2 5
    
    /** Output: **/
    The product of 2 and 5 is 10
    ```

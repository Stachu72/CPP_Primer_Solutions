# Exercise 1.9
>  Write a program that uses a while to sum the numbers from 50 to 100

## Solution

```c++
#include <iostream>
int main()
{
    int number = 50, sum = 0;
    while (number <= 100) {
        sum += number;
        number++;
    }
    std::cout << "The sum of the numbers from 50 to 100 inclusive, is: " << sum << std::endl;
    return 0;
}
```

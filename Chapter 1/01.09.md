# Exercise 1.9
>  Write a program that uses a while to sum the numbers from 50 to 100

## Solution

- **Code:**
    ```c++
    #include <iostream>

    int main() {
        int number = 50, sum = 0;
        while (number <= 100) { // check whether the number is still within the range (is smaller than/equal to 100)
            sum += number;      // | (sum = sum + number;)
            number++;           // | in each iteration, add the number to the total sum and increase that number by 1
        }
        std::cout << "The sum of the numbers from 50 to 100 inclusive, is: " << sum << std::endl; //print the sum
        return 0;
    }
    ```

- **Input/Output:**
    ```c++
    /** Output: **/
    The sum of the numbers from 50 to 100 inclusive, is: 3825
    ```

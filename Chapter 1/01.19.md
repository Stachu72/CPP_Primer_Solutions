# Exercise 1.19
>  Revise the program you wrote for the exercises in § 1.4.1 (p. 13) that printed a range of numbers so that it handles input in which the first number is smaller than the second.

<br/>

**Mentioned program**
```c++
#include <iostream>
int main()
{
    int numberA = 0, numberB = 0;
    std::cout << "Enter two numbers (the smaller one first), separated by a space: ";
    std::cin >> numberA >> numberB;
    while (numberA < numberB-1) {
        numberA++;
        std::cout << numberA << std::endl;
    }
    return 0;
}
```

## Solution

```c++
#include <iostream>
int main()
{
    int numberA = 0, numberB = 0;
    std::cout << "Enter two numbers, separated by a space: ";
    std::cin >> numberA >> numberB;
    // check if the first received input is larger than the second one
    if (numberA > numberB)
        while (numberA > numberB+1) {
            numberA--;
            std::cout << numberA << std::endl;
        }
    else
        while (numberA < numberB-1) {
            numberA++;
            std::cout << numberA << std::endl;
        }
    return 0;
}
```

# Exercise 1.22
> Write a program that reads several transactions for the same ISBN. Write the sum of all the transactions that were read

## Solution

```c++
#include "Sales_item.h"

int main()
{
    Sales_item book, collection;
    std::cin >> collection; //treat the isbn of the first read book as the referenced isbn
    while (std::cin >> book) {
        if (book.isbn() == collection.isbn())
            collection += book;
    }
    std::cout << collection << std::endl;
    return 0;
}
```

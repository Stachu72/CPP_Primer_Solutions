# Exercise 1.1 
>  Review the documentation for your compiler and determine what file naming convention it uses. Compile and run the main program from page 2.  

## Solution 

- A review of Microsoft's documentation shows that the recommended file name convention for source and header files are `.cpp` and `.h` respectively. However, other extensions are also supported such as `.c`, `.cxx`, `.hpp`, or `.hxx`.  There is no functional difference between these extensions, but it is advisable to use them for consistency and performance.
